## 1. 추천 콘셉트·재미·위험

추천 한 줄: 해골 한 마리로 첫 처치를 만들고, 그 시체로 30초 안에 제한된 해골 군단을 일으키는 소환사.

재미의 원리: 커서 원으로 적 무리 지정 → 자동 처치와 즉시 골드 → 토큰 누적·임시 해골 등장 → 공격 장면이 점차 풍성해짐 → 상점에서 다음 턴 시작 화력 또는 증식 속도에 투자. 골드는 구매 자원, 시체는 턴 내부 성장 계기다. 시체를 골드나 구매 레벨로 교환하지 않는다.

핵심 위험은 첫 처치가 어려우면 증식도 멈추는 양극화, 매 턴 군단 소멸의 상실감, 단일 보스의 시체 부재, 개체가 늘어도 같은 적에 몰리는 과잉 공격이다. 증식 수치만 늘리는 해결은 피한다. 가장 싼 검증은 동일 적 배치 위에 턴 시작·첫 증식·상한 도달 그림과 구매 카드 두 경로를 제시하는 종이 비교다. 이 문서의 사건 추적은 재미 입증이 아니다.

다른 직업과의 구분: 동물조련사는 구매한 무리가 시작부터 존재하나 네크로는 처치 이후에만 임시 수가 증가한다. 악마의 동일 적 표식 소비와 달리 서로 다른 적의 사망을 누적한다. 용의 한 개체 진화보다 턴 내 군단 밀도 변화가 중심이다. 다만 초반 처치 없는 보스에서는 영구 소환수의 성장 만족을 사용하며 역할 퍼즐을 필수화하지 않는다. 참고작 대비는 직접 무기 조작 대신 자율 접근하는 소환수와 유한 턴 증식이라는 설계 차이이지 시장 독창성·법적 차별성 입증이 아니다.

## 2. 불변 기준과 공통 계약

G1 기준: 기본 골드는 드랍 즉시 전액 자동 수집, 커서 지정 범위 안 몬스터만 공격, 지정 범위 확대 업그레이드 존재, 초기 전투 30초 고정·시간 증가 보류, 성장·시각 만족 우선·단순 화력 보스 허용. 보스 입장/실패/재도전 비용·패널티 없음, 재도전 HP 초기화. 무한 성장·환생 제외. 최종 보스 후 통계→메인 흐름 유지.

05의 세부 초안을 공통으로 채택하는 제안: command_radius=R_cmd, attack_range=R_reach, effect_radius=R_fx를 분리. 현재 유효 커서 원과 피해 형상의 교집합에만 피해. 원 밖 대체 타깃 없음. 준비·발사·명중 자격 검사, 비행 중 지정 이탈 즉시 투사체 무효화, 재진입 복원 금지. 광역·부가 피해에도 동일하다. 범위가 비면 대기, 소환수는 대상까지 자동 접근. 개별 스킬 클릭·시체 클릭·커서 고정 입력 없음. 아군 무피격 원안 유지, HP·희생·치유·아군 사망 추가 없음. 배치는 05 B01/B09의 고정 생성 슬롯과 추적 후 겹침 허용을 따른다. 임시 생성도 커서 위치나 시체 위치 순간이동이 아니다.

공통 세부는 대표가 별도 승인한 사항이 아니며 16/17 검토 대상이다. 예외를 이 직업만 몰래 허용하지 않는다. 표기하는 모든 피해·주기·거리·상한·가격은 비교용 가정이며 P1-12/14에서 통합한다.

## 3. 소환수 5종·공격·진화

Class: CLS_NEC, starter=SUM_NEC_SKELETON(initial_count=1), mechanic=EFF_CORPSE_RAISE. 기본 해골 외 추가 4종이다. 종류마다 영구 1마리만 보유하는 후보, 총 영구 상한 5·임시 상한 기본 3/업그레이드 후 5, 합계 최대 10(성능 보장 아님). 모든 소환수 slot_cost=1. unlock 획득은 상점에서 구매하고 다음 전투 준비부터 적용, 같은 런 내 유지한다. 임시 해골은 같은 정의를 공유하되 temporary=true, turn 수명이다. 기본 해골의 영구 진화·공격력 업그레이드를 같은 턴의 임시 해골에도 적용한다.

## 4. 시체 생성·소비·소멸·증식 규칙

### 4.1 EFF_CORPSE_RAISE 계약

- trigger=정상 적 사망 확정, target_selector=사망 사건(공격 피해는 cursor_eligible_only), operation=유한 토큰 적립/임시 생성, stack_rule=정수 누적, cap=3, reset_scope=battle_end, can_trigger_other_effects=false, reward_policy=추가 골드 없음.
- death_event_id는 battle_id+monster_id의 한 번뿐인 Alive→Dead 사건. 같은 시각 여러 공격·광역·진화·임시 해골의 처치도 적 한 마리당 기본 토큰 1개. 마지막 타격 소환수 종류와 무관. 정상 적 처치는 원 범위 자격을 충족한 피해에 의해서만 발생한다.
- 토큰은 바닥 시체 아이템이 아닌 정수 corpse_token_count. 시체 잔상은 입력/공격 대상이 아니고 최대 0.4초 시각 연출만 제안한다. 적 시체의 물리 오브젝트를 유지할 요구는 없다. 골드 지급 키와 토큰 중복방지 키는 동일 사망 사건을 참조하지만 별도 처리 완료 상태를 가진다. 토큰 누락 복구를 골드 재지급으로 처리하지 않는다.
- UPG_NEC_RAISE 구매 전 토큰 획득·보관 없음. 구매 후 정상 사망 사건마다 1개 추가, 3개 소비 시 임시 해골 1마리. UPG_NEC_THRIFT 후 비용은 2개. 현재 토큰 상한은 계속 3으로 유지한다. 슬롯·전투 진행 상태를 먼저 확인하고 성공하는 경우에만 토큰 소비. 생성 실패 시 토큰 유지하되 3 초과분은 즉시 폐기, 생성 부채 없음.
- 동일 시각 사망들을 작은 monster_id 순서로 한 건씩 처리: 단일 사망 확정·골드 1회 지급 → 토큰 min(3,기존+1) → 슬롯 있고 비용 충족 시 소비·임시 해골 생성. 다음 사망은 갱신 상태를 읽는다. 상한을 넘은 토큰은 이후 소급 복구하지 않는다. 임시 해골은 05 순서에 따라 같은 시각에 공격하지 않고 다음 논리 사건부터 후보를 선정한다.
- 임시 해골은 전투 끝까지 유지, 사망·수명 시간·자폭 없음. 따라서 임시 상한 도달 뒤 같은 전투에서 빈 슬롯이 생기지 않으며 토큰은 더 이상 전력이 되지 않는다. 원 밖에 아군이 있어도 임시 수에 포함된다.
- 정확히 T의 사망/스폰/토큰/공격은 없음. T 미만 사망의 골드는 즉시 유지하지만 종료 시 토큰·임시 해골·공격 큐·시체 잔상은 제거. 청소는 사망이 아니므로 골드·토큰 0. 구매 레벨·영구 진화·잔액은 유지. 다음 일반전/보스는 영구 목록만 복원하고 토큰0/임시0/발동횟수0에서 시작한다.

### 4.2 단일 보스와 악용 방지

보스가 죽기 전 정상 적 사망이 없으면 토큰0·임시0을 유지한다. 보스를 위해 졸개·시체 선지급·무료 시작 해골을 새로 추가하지 않는다. 영구 해골·리치·궁수 등의 구매 화력만으로 도전할 수 있게 보스 HP를 13/14에서 검토한다. 보스 사망은 토큰 처리 대상이더라도 승리 잠금이 생성보다 우선하며 임시 생성하지 않는다. 보스 골드/클리어 보상은 미정이므로 계산 원장에서는 0 가정. 실제 채택 시 보스 사망 지급 키도 한 번만 적용한다.

무료 재도전은 영구 구매를 박탈하지 않는 대신 보스HP·토큰·임시군·쿨다운·진형을 시작 상태로 복원한다. 잔여 시체/임시 해골의 이월·판매·골드 환전 없음. 임시 소환이나 종료 청소가 적 사망 이벤트를 만들지 않는다. 부가 피해는 다음 논리 사건으로 넘기며 재귀 소환/폭발 없음. 몬스터 공급 자체는 P1-13 유한 스폰 표에 종속되어 증식만으로 적이나 골드가 추가 생성되지 않는다.

## 5. 전용 업그레이드 카탈로그 — 14종 제안

필수 10필드+type을 아래 공통값과 행의 값을 합쳐 정의한다. 공통값은 모든 행에 명시 적용: category=summon, applies_to=CLS_NEC, currency=gold, unlock_condition=run_start(선행조건과 교집합), status=proposed. 비용은 현재 레벨 l=0부터 다음 구매 가격 C(l)=base×(l+1), 정수·반올림 없음, 최대레벨까지만 구매. 단발형은 base 한 번. 아래 가격은 통합 전 비교 가정이며 실제 구매시간/경제 균형을 검증한 값이 아니다. scope: M은 네크로 단독 최소 비교 후보, E는 확장 후보. 전체 게임 MVP 채택 여부는 §8.

반복 공격력은 진화로 정한 원천 피해에 (1+0.25×레벨)을 한 번 곱하는 제안, 임시 해골 포함. EFF_NEC_CONDUCT는 별도 +2를 마지막에 한 번 더한다. 복리/효과 중복 부착 없음. 공통 공격력 버프와 곱셈 순서는 12/14 통합 전 미정이므로 혼합 DPS를 확정하지 않는다. 표시 피해가 소수일 때 처리 방식도 14 확인 필요, 문서 비교에서는 소수 그대로 사용한다.

## 6. 트리·대표 빌드 2종

선행은 AND, 가지 간 배타 없음. 아래는 구매 도달성 설명이지 보스 진입 조건이 아니다.

    런 시작 → BONE(1~3) → GUARD → GOLEM → OSSUARY
            → RAISE → THRIFT
                    → LEGION(1~2)
            → LICH → ARCHLICH
            → ARCHER → SENTINEL
            → REVENANT → REAPER
    RAISE + LICH → CONDUCT
    GUARD + LICH → GOLEM (위 경로의 추가 AND)

A. 소생 군단 빌드: RAISE → THRIFT → LEGION1 → LEGION2 → BONE1. 임시가 늘어나는 시점을 앞당기고 상한까지의 여유를 늘린다. 시작 전력은 해골1, 첫 처치가 늦으면 손해이며 토큰 없는 단일 보스에 효과가 낮다. 밀집 일반전에서 후반 공격 장면을 원하는 선택. 첫 처치가 안 되면 BONE을 앞당기는 수정안과 비교한다.

B. 영구 지팡이 빌드: LICH → ARCHER → BONE1 → GUARD → ARCHLICH. 첫 순간부터 영구3마리이며 처치가 적은 적 배치·보스에서도 시작 화력이 남는다. 소생 장면은 RAISE를 나중에 사기 전에는 없고 군단 수 변화가 작다. 일반전에서 첫 처치 병목을 줄이지만 토큰 경로의 최대 임시5를 얻지 못한다.

두 경로는 같은 예산이 아니다. 구매 순서 예시를 동등 효율의 증거로 쓰지 않는다. 동예산 비교는 14에서 각각 28G의 RAISE+THRIFT와 28G의 LICH+BONE1부터 비교하도록 인계한다. 적 공급·이동·겹침·이탈로 실효 공격횟수가 달라져 명목 피해만으로 우열을 확정할 수 없다. 모든 업그레이드가 유한하며 구매하지 않은 항목 때문에 새 일반전을 막지 않는다. 최종 형태는 두 빌드가 합류할 수 있는 확장 종착점이다.

### 플레이 예시 — 실제 기록 아님

첫 전투에는 해골1로 원 안 적을 공격, 골드는 처치와 동시 지급된다. 상점에서 RAISE를 사면 다음 전투도 시작은 해골1이지만 세 번째 정상 처치 뒤 임시 해골1이 추가된다. 다음 두 번의 세 처치 묶음 뒤 임시3에 도달한다. 30초 종료 때 임시3은 사라지고 구매한 RAISE는 남는다. 상점 설명은 “다음 턴도 해골1에서 시작, 처치로 최대 임시3”이라고 알려 손실로 오해하지 않게 한다.

THRIFT 구매 후에는 두 처치마다 한 번씩 소생한다. 원을 옮겨 비행 중 리치 탄의 대상이 원 밖으로 나가면 탄은 취소되며 토큰·골드는 생기지 않는다. 보스 선택 시에는 정상 사망이 없어 증식이 없으므로 리치 등 영구 전력 투자 이유가 생긴다. 무료 재도전으로 임시군을 축적할 수 없다.

## 7. 경제·와이어프레임·추적 기록

골드 기대값은 합법 처치별 최종 정수 지급액 합이다. 토큰은 골드 생성 사건이 아니고 수집률 계수·바닥 손실·시체 판매가 없다. 임시군의 간접 처치 증가도 적 공급 상한을 넘지 못한다. 반경 확대는 지정 기회 증가이지 토큰 배수/골드 배수가 아니다. 상자는 이 직업의 필수 기능으로 채택하지 않는다.

가정 원장: 초기잔액0, 일반전1 처치10×2G=20, 상점 RAISE10 차감→10. 일반전2 처치12×2G=24 지급→34, THRIFT18 차감→16. 보스 실패 보상0 가정→16, 무료 재도전 차감0→16. 상점 정산은 이미 받은 골드 표시만 하며 재지급0. 처치 수는 설정한 입력값이지 실제 전투 수익 예측이 아니다. 종료 토큰 폐기는 잔액 차감이 아니다.

전달용 텍스트 와이어프레임(최종 UX 아님):

    남은 시간 | 보유 골드: 즉시 반영 | 일시정지
    +----------- 정사각형 전장 -----------+
    | 해골 / 리치    (커서 공격 지정 원)  |
    | 동전: 비상호작용 짧은 효과          |
    +------------------------------------+
    영구 1 | 이번 턴 임시 2/3 | 시체 토큰 1/3
    안내: 시체는 자동 사용, 임시 해골은 이번 전투만 유지
    상점: 가격 / 선행 / 다음 전투 시작 수 / 턴 내 최대 수

토큰 UI는 수집 버튼이 아니다. 지휘 원을 시체/파티클보다 우선 표시, 색만이 아닌 임시 테두리·실루엣 차이 제안. 16에서 토큰 세 숫자가 필요한지 검토하고 “다음 소생까지 처치 수” 한 줄로 줄이는 대안과 비교한다. 경제·테스트 추적 최소 필드: battle_id, death_event_id, 지급완료, 토큰처리완료, tokens_before/after, raise_cost, temporary_before/after, discarded_tokens, cap_blocked, 구매ID/레벨, 시작/종료 영구수·임시수, 지정 유효시간·이탈무효 공격·실제 지급골드. 시체/동전 그림 수를 보상 원장으로 사용하지 않는다.

## E02 H2 질문 순서 — MIA22-N01 / JAMES-04

가설 관찰 순서 정본(제안): H1 첫진입 → 자연경제 자유구간(H4/H5, 사전 노출 기록) → H2 명시 질문/경계과제 → H3 지정 구매과제 → 해금/실패 예측.

H2의 ‘첫전투 직후 설명 전 응답’은 질문·자료·정답 안내를 전혀 주지 않은 자발 발언/금화 추격 행동의 관찰 기록만을 뜻한다. 발언이 없으면 자발 발언 없음으로 기록하며 즉시 지급 이해 성공으로 채점하지 않는다. 질문을 던져 답을 얻지 않는다. H2 명시 질문은 자연 자유구간 종료 뒤에만 한다. 명시 질문으로 얻는 이해 판정과 첫전투의 무질문 행동 관찰은 별도 필드/시점이다.

H4의 ‘다음에 무엇?’ 질문도 H5를 유도할 수 있으므로 자연구간 내 H4 질문 전 H5 행동과 질문 후 H5 행동을 구분한다. 이 순서로도 H1 경험/화면 노출은 존재한다. 전체 세션 무노출·신규 유입 발견·장기 유지율 증거라고 해석하지 않는다. 순서를 위반한 세션은 exposure_deviation으로 표시하고 원계획의 미노출 분모를 채우지 않는다. 시점/결측/개입 기록 없이 통과 처리하지 않는다. 실제 참가자·대본 실행·결과는 없다.

## 1. 권고·범위·판단 기준

권고: 전투에는 원·대상·시간만 강하게 남기고, 턴 사이 상점에서 구매 결과와 다음 목표를 읽게 한다. 적 무리에 원을 옮긴다 → 소환수가 접근/공격한다 → 처치 즉시 잔액이 오른다 → 상점에서 원/군단/공격 형태의 다음 변화를 고른다. 전달할 감정은 수집 조급함이 아니라 지휘의 편안함과 성장의 확신이다.

[G1] 즉시 기본 자동 골드 지급, 현재 커서 지정 범위 안 적 공격·범위 확대, 성장/시각 만족, 일반전 초기30초 고정/시간 증가 보류, 무료·무패널티 보스/HP 초기화, 무한·환생 제외를 유지한다.

[선행 초안 인용] 중심 판정, 이동만 지정, 무피격, 모든 피해의 현재 지정 자격·비행 중 이탈 즉시 무효·재진입 비복원, [0,T), 분리 상점, 유한 해금집합/선택 보스/보상0 가정은 05/12/13의 제안이다. G1 확정으로 확대하지 않는다. 아래 배치·크기·색·연출 길이·표시 상한은 Mia의 세부 제안/가정이며 성능 실측값이 아니다. 핵심 입력·피격·경제·엔딩을 바꾸지 않는다.

미정 데이터는 UI에서 0/무료/기본값으로 추측하지 않는다. 용/동물 공격 원천 null, 최종 비용/보스HP/시간은 14/15에서 변경 가능. 카탈로그69항목과 5직업 화면 설명은 전량 제작 약속이 아니다.

## 3. 화면 배치와 마우스 계약

PC 마우스 중심의 검토 기준 캔버스1280×720을 가정한다(플랫폼 최종 확정 아님). 전투 상단64, 하단안내56, 바깥여백16을 확보하고 중앙 정사각형 필드는560×560 후보. 남는 좌우에는 군단 요약·범례만 배치한다. 실제 레이아웃 검사/렌더링은 미실행. 화면이 달라지면 필드는 비율 유지하고 좌우 요약은 하단 접기, 주요 버튼·타이머를 잘라내거나 전장 위로 덮지 않는다. 최소 지원 해상도는 Sam 검토/대표 플랫폼 결정 전 미정이다.

전투 중 필드에 소환수 상세 모달을 띄우는 호버 기능은 두지 않는다. 읽을 때는 화면 밖의 일시정지 버튼→정지 패널→정보 보기. 패널이 열리면05대로 시간/피해/이동 정지. 포커스 복귀는 자동 재개하지 않고 [계속]을 새로 눌러야 한다. 이때 포인터가 UI 위면 C 무효, 필드 재진입까지 공격하지 않는다. 단순 필드 이탈은 시계가 계속 흐른다는05 제안을 유지하므로 주변 버튼과의 불필요한 왕복을 줄인다.

표준 화살표 커서16~24px 후보+별도 지면 원. 커서 화살표의 클릭 핫스폿은 바꾸지 않는다. 접근성 커서 확대는 핫스폿/지정 반경을 바꾸지 않는다. 원 자체를 큰 마우스 포인터/골드 수집 영역으로 만들지 않는다. 필드 밖에서는 원을 숨기고 ‘전장에 커서를 두면 공격합니다’ 고정 안내. 원 안 적0이면 원을 점선으로 바꾸고 ‘원 안에 대상 없음’; 유효 후보가 있으면 실선. 일시정지는 별도 정지 배지여서 대상 없음과 구분한다.

UI 클릭은 버튼 안 누름→같은 버튼 안 놓음 때 단일 확정. 벗어나 놓으면 취소. 카드 선택·구매·다음전투는 별도 액션이다. 홀드 자동반복/일괄구매 없음. 구매 성공 뒤 같은 버튼은 포인터를 한 번 떼고 재진입해야 다시 활성화하는 후보로 연속 더블클릭의 의도치 않은 다음레벨 구매를 막는다(입력 세부 James/Sam 검토 대기). 요청 재처리 중은 ‘처리 중’ 비활성, 조건/가격 재검사. 전환 때 이전 누름/놓음/더블클릭 큐 폐기, 새 화면의 버튼은 새 입력 쌍을 요구한다. 일시정지·메인·설정도 마우스 버튼 제공, 키보드 단축키를 필수로 요구하지 않는다.

## 4. 상태별 텍스트 와이어프레임

기호: S=소환수, M=몬스터, +=판정 중심, C=포인터, ( )=공격 지정 원. 숫자는 예시/가정, 가격은12-v01 값이며14/15 수정 가능하다.

### W01 직업 선택·준비

    [메인]                              [설정]
    소환사를 선택하세요
    [정령: 선택됨] [용] [동물] [악마] [네크로]
    + 선택 직업 상세 -------------------------+
    | 정령소환사 / 시작: 불씨1                 |
    | 처음: 단일 탄 → 성장 후보: 개화·연쇄    |
    | 원 안의 적을 자동 공격 / 골드 자동 획득  |
    | [선택 확인: 정령소환사]                 |
    +-----------------------------------------+
    다음: 전투 준비 (선택 전에는 비활성)

선택만으로 전투가 시작되지 않는다. 기본 소환수/첫 장면을 보여주고 숫자 등급/난이도 단정은 쓰지 않는다. MVP에서 미채택 직업은 빈 잠금 타일 대신 목록 자체 제외 권고. 5직업 비교 기획이 실제5직업 선택 제공을 뜻하지 않는다.

    일반전 준비 / 30초 / 골드는 자동으로 지급됩니다
    +--------------- 정사각형 전장 -------------+
    | 첫 적 배치의 비활성 예고    S1            |
    | ‘원을 적 무리에 옮기세요. 클릭 불필요.’   |
    +------------------------------------------+
    출전: 불씨1 / 공격: 단일 / [정보]
    [전투 시작]   [직업 선택으로] (첫 시작 전)

준비에는 시계/공격/골드 없음. 전투시작 버튼을 놓아 준비가 끝나고, 필드에 커서가 들어와야 지정 유효. 첫 적 예고와 실제 첫 스폰을 이중 생성하지 않는다. 이미 런이 진행된 상점에서는 직업변경 버튼을 제공하지 않는다.

### W02 일반 전투

    일반전 01   남은 29.8초   보유 12G (이번 전투+2G)   [일시정지]
    출전 요약        +----------- 정사각형 필드 ------------+
    불씨1 영구       | S →   ( C    M+ [지정] )             |
    단일 / 대기1     |        (      M+       )    M+       |
    [범례]           | 원 밖 M은 어두운 중심표시·피해없음   |
                     | 동전은 짧은 장식, 클릭/잔존재화 없음 |
                     +------------------------------------+
    원 안의 적을 소환수가 자동 공격합니다. 금화는 자동 획득됩니다.

전투에 구매 버튼/상점 패널 없음. 적 중심 표식은 몸체 아래 바닥앵커에 붙이고, 큰 그림에는 중심과 바닥앵커를 연결하는 짧은 세로 표시를 쓴다. 실제 좌표·판정 중심은05의M 그대로이며 임의 보정하지 않는다. 지정 가능 적은 중심 마름모 테두리+작은모서리 강조, 실제 아군 타깃은 추가 한 개의 작은 꺾쇠. 유효 후보와 공격 중 대상을 같은 표식으로 뭉개지 않는다. 원 안이어도 사거리 밖이면 소환수 머리의 짧은 이동 화살표/요약 ‘접근 중’, 피해0을 버그처럼 반짝이지 않는다. 전체 사거리 원은 상시 표시하지 않고 정지 정보에서 선택한 개체 하나만 얇은 파선+‘공격 사거리’로 표시. R_fx는 실제 유효 적중 순간 짧은 고리, 지정 원보다 낮은 대비. 원 밖 부분은 약한 장식이며 피해 대상으로 강조하지 않는다.

이탈 무효 탄은 그 자리에서 짧게 축소/흐려짐, 적중 번쩍임·피해 숫자·동전 소리 없음. 최초 발생 때만 ‘지정 원을 벗어나 공격 취소’ 안내, 이후 고정상태 문구/검토용 카운터로 집계. 매 취소마다 토스트/경고음은 피로하므로 금지. 더 빠른 탄/짧은 준비는 규칙 데이터 변경이어서James 검토 사항이며 본 UI가 자동 적용하지 않는다.

### W02-C 미채택 상자 비교안(기본 화면 아님)

05 B후보를 채택할 때만 사용. 상자 마름모상자 실루엣+뚜껑 아이콘, 적 중심표식과 형태를 구분. 상자 위에서도 C유효·적 공격 지속. 클릭은 화면에 이미 보인 최상위상자1개만, 최근생성 우선/동시생성 큰ID. 상자 뒤 적·하위상자에 클릭 전파 없음. 같은 보너스는 Opened 또는 Settled 한 번만 지급. 상자 hit영역 확대가 실제 C/지정 원 중심을 옮기면 안 된다. 적을 가리면 아이콘을 살짝 비켜 표시하고 앵커선 유지; 히트영역은 겹침우선순위에 일치시켜 보이지 않는 상자를 클릭하게 하지 않는다. 기본 골드는 상자에 담아 보류하지 않는다. 종료 시 미개봉 손실·수집률을 표시하지 않는다. 현재 미채택이므로 UI09는 누락이 아니라 채택 경계 기록이다.

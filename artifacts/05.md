## 0. 추천과 해석 경계

추천 한 줄: “원을 몬스터 무리에 가져가면 소환 군단이 자동으로 접근·공격하고, 골드는 즉시 쌓이며, 구매 뒤 더 넓고 화려하게 처리하는 유한 성장 게임.”

재미의 원리: 적 무리 지정 → 소환수의 자동 공격과 즉시 보상 관찰 → 공격력·수량·진화·공격 지정 반경에 투자 → 다음 전투에서 동시에 다룰 수 있는 적과 화면의 변화 확인. 역할 변화형 군단은 선택 후보이지 필수 차별화 조건이 아니다. 단순 화력 성장도 유효한 비교 기준이다.

핵심 위험: 커서 밖으로 조금만 나가도 투사체가 무효가 되면 허공 공격처럼 보일 수 있다. 반대로 범위 밖 피해를 허용하면 대표의 지휘 방향을 무효화할 수 있다. 군단 이동 지연과 과잉 집중도 성장 만족을 낮출 수 있다.

가장 싼 검증: 동일 적 배치의 범위 확대 전후 도식, 범위 이탈 직전/직후 사건표로 이해와 논리 충돌을 먼저 검토한다. 실제 반복 피로·명중감·화려함은 별도 승인 후 조작 가능한 테스트에서 검증해야 한다. 이번에는 문서상 수기 추적과 문서/산술 검사만 수행한다.

표기 규칙:
- [G1] 실제 결정으로 확정: 드랍 즉시 기본 자동 골드 수집, 커서 지정 범위 안 몬스터 공격, 지정 범위 확대 업그레이드, 성장·시각 만족 우선, 초기 전투 30초 고정/시간 증가 보류, 보스 입장·실패·재도전 비용/패널티 없음·재도전 HP 초기화, 무한/환생 제외.
- [원안 유지 상세화] 정사각형, 마우스 중심, 소환수 기본 한 마리, 전투 후 상점, 개별 소환수 직접 조종 없음. 무피격을 유지하며 소환수 HP·사망·회복 체계를 추가하지 않는다. 이는 G1이 피격 체계 전체를 별도 열거 승인했다는 뜻이 아니다.
- [제안] 아래 §1~9의 G1 외 세부 규칙 전부. 후속 문서가 사용할 일관된 초안 계약이며 승인 사양이 아니다. 모든 예시 수치는 검증용 가정값이다.
- 핵심 입력/피격 방향 변경은 대표 재확인 전 적용 금지. 보스 해금·보상·구체 시간/연출은 P1-12/13, 경제 수치는 P1-14/15, 시각 표현은 P1-16, 구현 방식은 Sam/P1-17의 후속 영역이다.

## 1. 공통 좌표·판정 용어 [제안]

전장은 정사각형 F=[0,L]×[0,L], 예시 L=1000 전장 단위다. 화면 픽셀이 아니라 전장 좌표로 판정하고 화면 크기 변경 시 같은 비율로 표시한다. 개체 중심은 위치 앵커이며 그림 크기·파티클은 판정에 영향이 없다. 장애물·고저차·시야 차단·개체 간 물리 밀어내기는 초기 계약에서 제외한다.

| 기호 | 뜻 | 적용·경계 |
|---|---|---|
| C | 유효한 현재 포인터의 전장 좌표 | 포인터가 필드 위이고 가림 UI·모달에 잡히지 않은 경우만 유효 |
| R_cmd | 공격 지정 반경 | 원 중심 C, 경계 포함. 몬스터 중심 M에 대해 거리(C,M) ≤ R_cmd이면 지정 후보 |
| R_reach | 소환수 개별 공격 사거리 | 소환수 중심 S와 대상 중심 M 사이 거리 ≤ R_reach일 때 공격 가능 |
| R_fx | 폭발/연쇄 등 피해 형상 | 지정 후보 중에서도 해당 공격 형상에 포함된 대상에만 피해 |
| T | 해당 전투 제한시간 | 초기 일반전 30초 [G1]. 보스도 초기 30초로 비교하는 제안이며 구체 보스 계약은 P1-13에서 확인 |
| combat_id / entity_id / attack_id | 전투·개체·공격 식별자 | 전투 내 개체ID는 중복/재사용하지 않으며 보상 키는 combat_id+entity_id |

R_cmd는 골드 수집 반경이 아니다. 골드에는 수집 거리·커서 접촉·수집률·바닥 대기 시간이 없다. R_reach를 늘려도 지정 후보는 늘지 않고, R_cmd를 늘려도 먼 적을 그 자리에서 때리게 되는 것은 아니다. 둘은 별도 성장 축이다. 예시 시작 R_cmd=150, 비교 확대=250, 근접 R_reach=40, 원거리 R_reach=300. 최대 반경/레벨/비용은 P1-12/14 제안 대상이며 전장 전체 지정을 기본 종착점으로 확정하지 않는다.

큰 몬스터와 보스도 중심 판정으로 통일한다. 가장자리 그림만 원에 걸친 경우 지정되지 않는다. 대안인 원-몸체 교차 판정은 큰 보스 지정이 쉬우나 직업/크기에 따른 유효 반경이 달라진다. 중심 판정을 우선 권고하며 Mia는 중심 앵커를 읽을 수 있는 표시를 제안한다.

## 2. 자동 전투 필수 10항목 [G1 외 제안]

### B01. 소환수 생성 위치

전투 준비 시 구매 상태에서 소환수 목록을 복원하고 종류ID→구매 순번→개체ID 순으로 슬롯을 배정한다. 기본 한 마리는 필드 중앙. 추가 개체는 중앙에서 바깥으로 채우는 고정 격자 슬롯(행 우선, 동거리면 y→x 작은 순)이다. 예시 슬롯 간격 60, 가장자리 여백은 해당 개체 표시 반경 이상. 커서 위치에서 생성하지 않는다. 준비 단계에는 공격·골드·시간 진행 없음. 시작 후 전투 도중 새 소환이 허용되는 직업은 B09의 빈 슬롯 규칙을 사용한다.

### B02. 몬스터 생성 위치

종류/주기/수량/HP/보상은 P1-13의 유한 스폰 표에서 받는다. 일반전은 유효 전투 시작 시 첫 묶음을 생성하고 이후 예약 시각에 생성한다. 생성 중심은 필드 내부의 격자 후보 중 표시 반경만큼 경계 안쪽인 위치. 준비된 난수 시드로 순서를 정하고 현재 몬스터와 겹치지 않는 첫 후보를 사용한다. 소환수와의 겹침은 허용하되 읽기 어려움은 후속 검토한다. 커서 안/밖 여부로 스폰을 편향하지 않는다. 마땅한 슬롯이 없거나 개체 상한 도달 시 해당 예약은 건너뛰고 골드/추가 보상 없이 로그상 누락 수만 남긴다. 밀린 몬스터를 나중에 한꺼번에 생성하지 않는다. 보스전의 기본 후보는 중앙 보스 한 개체, 일반 스폰 없음(P1-13 제안 확인 필요).

스폰 직후부터 살아 있는 대상으로 지정 가능하며 무적 대기 시간은 두지 않는다. 첫 전투 준비와 함께 적이 잠깐 보이는 연출은 가능하나 준비 중 처치·보상은 없다. 동시 몬스터 상한의 실측값은 없으며 P1-13/17이 가정별 후보와 비용을 비교해야 한다. 이 문서가 새 수량의 제작을 확정하지 않는다.

### B03. 소환수·몬스터 이동

소환수는 지정된 대상이 R_reach 밖이면 대상의 현재 중심을 향해 직선 이동하고 사거리 경계에서 멈춘다. 매 판정 시각 현재 위치를 다시 읽는다. 대상이 없으면 현재 위치에서 대기한다(중앙 자동 복귀 없음). 커서를 직접 추종하거나 커서에 붙여 순간이동하지 않는다. 커서를 멀리 옮겨도 소환수는 속도대로 이동한다. 예시 소환수 속도=400 단위/초. 사거리 안에서 조준 준비 중에는 이동하지 않으며 유효 대상이 사거리 밖으로 나가면 준비를 취소하고 추적한다.

일반 몬스터는 정해진 속도·방향의 직선 배회, 가장자리에서 반사. 예시 속도=40. 보스 기본 후보는 중앙 정지. 몬스터는 소환수를 공격·추격·밀어내지 않고 접촉 피해도 없다. 개체 겹침 허용으로 길막·교착을 피한다. 예시 속도는 실제 밸런스가 아니다. 정지 몬스터안은 더 저렴하지만 지정 이탈/재추적 검증이 어려우므로 배회안을 초안 기준으로 권고한다.

### B04. 공격 대상 선정

각 소환수는 살아 있음, 현재 전투 소속, C 유효, 거리(C,M) ≤ R_cmd를 모두 만족하는 후보만 탐색한다. 현재 대상이 여전히 후보이면 유지한다. 없거나 무효가 되면 소환수 중심에서 가장 가까운 후보, 거리 동률이면 작은 entity_id를 선택한다. 큰 적/저HP/보스 우선 규칙은 기본값에 없다. 대상 선정은 소환수ID 순서로 수행하지만 예상 피해 예약이나 대상 독점은 하지 않아 여러 소환수가 같은 적을 고를 수 있다.

후보 없음: 추적/조준 준비 중단, 대상 해제, 현재 위치 대기. 지정 범위 밖의 적을 대체 타깃으로 잡지 않는다. 커서가 빈 공간에 있거나 필드 밖이면 같은 처리다. 재진입 시 새 후보를 자동 선정한다. 클릭으로 대상 고정하거나 마지막 지정 원을 남기는 기능은 없다. 유지 대상이 살아 있어도 원 밖이면 즉시 무효다. 공격 허가는 공격 시작·발사·명중마다 재확인한다.

### B05. 근접 및 원거리 공격

공통 주기: 대기/추적 → 사거리 진입 → 준비(windup) → 발사 또는 근접 타격 → 쿨다운 → 다음 공격. 처음에는 쿨다운 0. 예시 준비 0.2초, 쿨다운 1초(발사 직후부터 다음 준비를 재개할 수 있을 때까지), 투사체 속도=600. 이동·추적은 쿨다운 중에도 가능하지만 새 준비는 쿨다운 종료 뒤 시작한다. 따라서 쿨다운을 발사 간격과 혼동하지 않는다. 준비 도중 대상 사망·지정 이탈·사거리 이탈은 취소하고 쿨다운을 새로 소비하지 않는다. 발사/타격이 성립하면 쿨다운 소비. 타깃 없는 시간에도 이미 소비한 쿨다운은 흐르지만 준비된 공격을 여러 번 비축하지 않는다. 준비와 쿨다운 수치는 공격별 데이터로 바꿀 수 있으나 판정 원칙은 공통이다.

근접: 준비 완료 시 대상의 지정·생존·사거리를 재확인하고 즉시 피해 사건 1회. 애니메이션의 추가 접촉은 추가 타격이 아니다.

원거리: 발사 때 지정·생존·사거리를 확인하고 해당 entity_id만 추적하는 투사체 1개 생성. 발사 후 대상이 R_reach 밖으로 가도 비행은 지속하되 현재 지정 범위 밖으로 나가거나 사망하면 즉시 무효화한다. 다른 적으로 유도 대체하지 않는다. 명중 때 생존·현재 지정 범위·전투 진행 상태를 재확인한다. 무효화된 투사체는 대상이 나중에 다시 들어와도 살아나지 않으며 이미 소비한 쿨다운은 환불하지 않는다. 투사체 최대 수명은 예시 2초, 만료 시 피해 없이 제거한다. 전장 밖·전투 종료도 제거 조건이다. 충돌 경로상의 다른 몬스터는 맞지 않는다.

이탈 무효화는 엄격한 G1 해석의 세부 제안이지 대표가 선택한 투사체 방식이 아니다. 발사 시 허가 고정안과의 비교는 §5에 둔다.

### B06. 몬스터 사망

동일 판정 시각의 유효 피해를 대상별 합산 후 HP를 0 이하로 만든 개체를 Alive→Dead로 한 번만 전환한다. 죽은 개체는 즉시 후보에서 제외한다. 죽음 연출 잔상은 공격·클릭·이동 충돌 대상이 아니며 골드 지급을 기다리게 하지 않는다. 마지막 타격 소환수에게 추가 골드·경험치를 주지 않는다. 여러 타격이 같은 시각에 들어와도 처치 수·골드·상자 추첨은 개체당 1회다. 원안에 없는 소환수 사망·희생을 공통 규칙으로 넣지 않는다. 직업별 처치 연동 효과 후보는 같은 사망 사건을 읽되 독자적인 추가 보상/증식 상한 계약이 필요하다(P1-06~11).

### B07. 골드 드랍·자동 지급

[G1] 정상 사망 확정과 같은 논리 사건에서 정수 골드 G를 보유액과 해당 턴 획득액에 즉시 1회 더한다. 지급 키는 combat_id+entity_id. 보상량과 배수/반올림 순서는 P1-14/15에서 정할 데이터 계약으로 받고 이 문서는 최종 정수 G를 사용한다. 커서 위치, 동전 그림 수, 애니메이션 도착·프레임 누락으로 지급을 지연·감소시키지 않는다. 드랍 그림은 짧은 비상호작용 효과이며 클릭/호버/바닥 잔존 재화가 아니다. 상점 정산은 이미 지급한 턴 합계를 보여 줄 뿐 잔액에 재가산하지 않는다. 경계 복구/강제 제거·시간초과 청소는 처치가 아니므로 보상을 주지 않는다.

보유 잔액과 구매는 턴 사이 유지 [제안]. 턴 종료 미수집 골드 소멸은 폐기: 애초 미수집 골드 원장이 없다. 보스 골드/상자/실패 보상은 G1이 정하지 않았다. P1-13에서 채택 전까지 수입 예측에 포함하지 않으며, 비교 원장에서는 보스 보상 0을 가정한다. 무료 재도전은 실패 보상을 추가한다는 뜻이 아니다.

### B08. 범위 공격 및 다중 공격

일반 공격은 한 대상. 범위/연쇄/관통은 후속 직업 데이터에 명시된 경우에만 적용한다. 모든 2차 피해에도 현재 R_cmd 조건을 동일하게 적용한다. 폭발은 유효한 주대상 명중 위치를 중심으로 R_fx 이내이면서 지정 후보인 적만 맞는다. 주대상 무효면 폭발도 없다. 연쇄는 각 연결 시점 지정 후보 중 미피격·연쇄 사거리 이내의 가장 가까운 적, 동률이면 작은 ID; 최대 대상 수까지, 없으면 조기 종료. 한 공격ID는 같은 적에게 최대 1회 피해. 주대상 포함인지 최대 수 필드에 명시하며 기본은 포함이다. 예시 최대 대상 수=3이면 전체 3개체다.

관통 후보도 지정 범위와 경로 형상의 교집합만 피해를 받는다. 원 밖에 효과가 그려져도 피해는 없다. 도트/지속 장판이 후속 후보가 되면 매 피해 시점 지정 범위를 검사하고 밖에서는 피해를 주지 않는 원칙을 따른다. 초기 필수 구현으로 추가하지 않는다. 죽음 효과·파티클에는 독립 피해가 없다. 지정 반경 확대가 다중 공격 대상 수 상한이나 R_fx까지 늘리지는 않는다.

### B09. 다수 소환수 배치

구매 수량 N은 다음 전투 준비 때 정렬된 고정 슬롯에 복원한다. 전투 중 적 추적으로 슬롯은 해제되며 겹침을 허용한다. 공격 중 서로를 밀거나 공격을 막지 않는다. 전투 중 증식 후보는 가장 낮은 빈 생성 슬롯, 없으면 중앙 생성(겹침 허용). 증식은 직업별 유한 상한 이내에서만 가능하고 상한 도달 시 생성 실패·보상 없음·추가 생성 부채 없음. 직업 수량 상한은 P1-06~11/17, 화면 효과 상한은 P1-16/17 검토 대상이다. 임의로 구매 수량을 성능 때문에 몰래 줄이지 않는다. 슬롯 부족은 렌더 겹침으로 처리하고 수량 제한 변경은 기획 협의한다.

목표 분산 대안은 과잉 공격을 줄이지만 피해 예약/재배정·UI 복잡도가 증가한다. 기본은 대상 공유 허용. 과잉 공격 때문에 구매 체감이 사라지는지 실제 검증한 뒤 조정하며 이 문서에서 예약 시스템을 필수화하지 않는다.

### B10. 경계 및 이탈

개체 중심의 이동 허용 영역은 그림의 표시 반경만큼 안쪽인 정사각형이다. 소환수는 해당 경계에서 멈추고 여전히 합법 후보를 추적한다. 몬스터는 넘은 이동 거리를 반사하여 필드 안 배회를 유지한다. 보스 중심은 고정. 잘못된 데이터로 밖에서 발견한 Alive 개체는 가장 가까운 유효 위치로 복구하고 HP·ID 유지, 피해·처치·골드 없음. 복구 뒤 지정/사거리 재판정한다. 반복 복구는 결함 신호이지 게임 보상이다.

포인터가 필드 경계선 위면 유효, 경계 밖이면 무효. 마지막 C에 고정하거나 가장자리로 자동 클램프하지 않는다. 원이 가장자리에 걸치면 필드와 겹치는 부분만 사용하고 반경을 안쪽으로 이동시키지 않는다. 필드 밖 투사체는 피해 없이 제거. 몬스터/소환수가 필드 밖으로 탈출해 영구 타깃이 되는 흐름은 허용하지 않는다.

## 3. 커서·상자·입력 우선순위 [제안]

### 3.1 기본 입력

포인터 이동만으로 R_cmd가 이동하며 누르고 있기·연속 클릭·적 몸체 접촉은 필요 없다. 필드 클릭은 공격 추가 발동·속도 상승·타깃 고정을 하지 않는다. 우클릭·드래그·휠·수동 스킬은 기본 전투에 기능 없음. 상점은 전투와 분리하고 전투 중 구매 불가. 키보드 없는 일시정지는 별도 화면 버튼으로 접근할 수 있도록 Mia에 검토 요청한다.

입력 처리 우선순위:
1. 전투 종료/전환 잠금: 종료 시각 및 이후 전투 입력 폐기. 이전 화면 버튼의 남은 클릭은 새 화면으로 전달하지 않음.
2. 일시정지·모달·앱 포커스 상실: 전투 시간·이동·피해·드랍 정지, 클릭은 해당 UI만 처리. 복귀 때 계속 버튼 확인 후 재개. 저장/오프라인 보상으로 확대하지 않음.
3. 활성 화면 UI: 버튼·모달이 포인터를 점유하면 그 위치의 필드 C는 무효. 필드 위 장식/골드 연출은 입력을 점유하지 않음.
4. 선택 후보인 필드 상자: 좌클릭 1회는 최상위 상자 1개만 개봉, 아래 적/다른 상자로 클릭 전파 없음. 상자는 적이 아니며 자동 공격 대상 아님.
5. 필드 이동: C 갱신, 자동 지정/공격 판정. 클릭 유무와 무관.

상자는 필드 오브젝트이므로 상자 위에 포인터가 있어도 C는 유효하며 그 위치 원 안의 적은 계속 공격한다. 상자 클릭은 자동 공격을 멈추거나 커서를 고정하지 않는다. 상자 여러 개 중첩 시 최근 생성된 상자 우선, 동시 생성이면 큰 상자ID 우선. 클릭은 누름 시작의 1회 사건으로 취급하고 홀드·더블 클릭의 후속 사건은 이미 Opened인 같은 상자에 보상을 다시 주지 않는다. 상점 구매 등 화면 버튼의 세부 입력은 P1-16에서 통일한다.

### 3.2 상자는 기본 골드와 분리된 미채택 후보

원문 L190~199의 클릭 상자 요구를 삭제하지 않고 다음 두 안을 비교한다.
- A 미개봉 소멸: 클릭 순간만 보너스 지급. 단순하지만 종료 직전 손실·수집 노동을 재도입한다.
- B 클릭 조기 개봉+종료 자동 정산: 클릭 시 보너스를 먼저 확인, 미개봉 상자는 종료 시 같은 보너스를 자동 지급. 손실은 없으나 클릭 필요성이 약해진다.
권고는 상자 없는 최소 전투를 먼저 검증하고, 상자를 채택한다면 B를 비교 후보로 사용한다. B는 G1이 승인한 사양이 아니라 P1-12/16/18에서 판단할 새 제안이다. 기본 골드를 상자 안에 넣어 클릭까지 보류하는 것은 금지한다.

B 후보의 완결 계약: 사망당 상자 추첨은 1회, 생성 때 정수 보너스 H와 상자ID를 정해 두되 기본 골드 G는 즉시 지급. Closed→Opened(유효 좌클릭) 또는 Closed→Settled(종료 자동 지급) 중 한 경로로만 H 지급. 이후 재클릭/재정산 무효. 미개봉 정산은 종료 직전까지 합법 생성된 상자만 대상으로 하고 새 드랍 추첨을 하지 않는다. 추가 보상·희귀도·통화는 넣지 않는다. 결과 화면에는 기본 골드와 상자 보너스를 구분한다. 이 후보를 채택하지 않으면 상자 상태/보너스는 모두 없는 기본안이다.

원은 커서 크기나 금화 습득 범위를 뜻하지 않는다. 지정 가능 적 강조, 원 밖 투사체 무효화 표시, 중심 앵커·소환수/몬스터/상자 레이어는 Mia/P1-16 제안 대상이다. 숫자/파티클보다 지정 원과 대상을 우선 읽을 수 있어야 한다.

## 4. 상태 전이·동시 사건·종료 [제안]

### 4.1 전투 상태

준비(구매 상태 복원·배치, 시간 0 정지)
→ 시작(필드 입력 활성·첫 스폰)
→ 일반전 진행 [0,T)
→ 종료 잠금 → 정산 표시 → 상점(시간 정지)
→ 구매 또는 저축 → 일반전 준비 / 해금된 경우 보스 준비

보스 진행 → T 미만 처치 확정 → 승리 잠금 → 클리어/통계 → 확인 → 메인.
보스 진행 → 제한시간 도달·생존 → 실패 잠금 → 상점 → 무료 보스 재도전 / 일반전 선택.
보스 해금/선택 도전은 기존 초안의 제안이며 P1-13에서 확정할 항목. G1의 무료·무패널티·재도전 HP 초기화는 반드시 유지한다. 보스 HP 일부 누적·입장 재화 차감·실패 구매 초기화 없음. 완전 클리어 후 무한/환생 루프로 연결하지 않는다.

전투 종료 때 제거: 몬스터, 소환수의 전투 위치/임시 상태, 투사체, 현재 대상, 임시 증식, 타이머, 입력 큐. 유지 제안: 직업, 구매·진화, 보유 잔액, 보스 해금. 다음 전투는 구매 상태를 새로 복원하고 보스는 최대 HP로 시작한다. 같은 전투 정산은 한 번이며 전투 종료 제거를 사망으로 처리하지 않는다. 저장·새 게임/이어하기 정책은 별도 미정이다.

### 4.2 소환수 상태

대기 ↔ 추적 → 준비 → 공격 성립 → 쿨다운 → 대기/추적/준비.
대상 무효: 대기/추적/준비의 대상 해제. 발사된 투사체는 별도 생명주기, 무효면 제거. 쿨다운은 대상 없어도 진행. 종료면 모든 전투 상태 폐기. 무피격이므로 사망/기절/회복 상태 없음. 일시정지는 상태를 보관하고 시간만 정지하며 재개 시 현재 C를 다시 검증한다.

### 4.3 시간 및 동시 사건 순서

유효한 사건 시각은 0 이상 T 미만. 정확히 T의 타격·클릭·스폰은 처리하지 않고 종료한다. 종료 이후 투사체 명중·늦은 연출 콜백은 피해/골드를 만들지 않는다. 화면 프레임 시각이 아니라 전투의 논리 사건 시각으로 판단해야 하며 구체 시간 처리 방식은 Sam이 검토한다.

같은 유효 시각의 순서:
1. 입력/일시정지 상태 확정. 종료 시각이면 아래 단계 대신 종료 잠금.
2. 해당 시각 예약 스폰, 개체 이동·경계 복구, 현재 C와 지정 후보 갱신.
3. 기존 투사체 무효/만료 처리, 표적 선택·추적/준비 판정, 발사/근접 타격 및 도착 투사체의 유효 피해 수집. 동일 시각 피해는 단계 시작의 생존 상태로 모아 대상별 합산.
4. 사망을 개체별 1회 확정 → 기본 골드 즉시 지급 → 상자 채택 시 추첨/생성 → 처치 연동 후보 사건. 이 시각 새로 생긴 효과의 추가 피해는 다음 논리 사건 이후만 허용해 무한 재귀를 막는다.
5. 이미 화면에 제시된 상자에 대한 해당 클릭 처리. 클릭 시점에 표시되지 않았던 새 상자로 입력을 옮기지 않는다.
6. 보스 사망이면 승리 잠금. 그렇지 않으면 다음 사건 진행.

동시 처치는 여러 개체가 같은 시각 죽을 수 있다는 뜻이며 지급은 개체별 1회다. 마지막 보스 타격이 T 미만이면 승리, 정확히 T이면 실패. B 상자 후보의 종료 자동정산은 종료 이전 생성 상자만 결산하는 별도 정산 사건으로 피해/스폰 금지 이후 수행한다. 승패/정산 화면의 동일 좌표에 버튼이 있어도 이전 클릭을 재사용하지 않는다.

성장 후: 동일한 적 배치와 이동 조건에서 지정 반경 150→250의 가정 비교. 이전에는 한 무리만 포함하던 원에 인접 무리도 들어온다. 소환수 수량/사거리/공격 형태가 뒷받침될 때 더 많은 대상을 처리할 기회가 생긴다. 반경 확대만으로 즉시 피해 증가나 골드 배수를 지급하지 않는다. 여러 소환수가 같은 한 마리에 몰리면 성장 효과가 기대보다 작을 수 있다. 이 경우 적 종류를 늘리는 대신 집중·접근 병목부터 확인한다.

새 재미 가설(미검증):
- H1 지휘 이해: 원 안 적만 자동 공격하고 금화는 자동이라는 것을 설명할 수 있다. 범위/수집을 혼동하거나 클릭을 반복하면 전달 실패 신호다.
- H2 성장 식별: 같은 배치에서 구매 전후 원 크기·군단 수·공격 표현의 변화와 다음 목표를 알아볼 수 있다. 골드 숫자 외 차이를 못 찾으면 연출/성장 전달을 수정한다. 전략 역할 변화 이해를 필수 합격으로 강요하지 않는다.
- H3 반복 부담: 원을 한 무리에 유지하는 관찰과 다음 무리로 이동하는 개입이 편안하다. 계속 급히 원을 쫓거나 빗나감 때문에 짜증이 난다는 관찰은 실패 신호다. 실제 반복 피로는 문서만으로 검증 불가.

가장 싼 실험 설계(미실행): 두 장의 동일 전장 도식으로 전후 차이·커서 역할을 자기 말로 설명하게 하고 경계 사례의 결과를 예측하게 한다. 숫자 수입을 재미의 증거로 삼지 않는다. 실제 승인 후에는 상자/스킬 없는 기본 입력부터 테스트해 반복 클릭 횟수·지정 부재 시간·이탈 무효 타격·구매 변화 설명·자발적 재시작 이유를 관찰한다. 수집률 대신 지정/공격/처치 경로를 본다. 표본·성공 기준·테스트 시간은 P1-18에서 제안하며 실제 참가자 결과는 없다.

## 1. 추천과 재미 가설

추천 한 줄: 작은 불씨의 단일 탄을 폭발로 키우고, 번개와 다른 정령을 더해 원 안의 적을 처리하는 장면이 점점 풍성해지는 유한 성장 소환사.

재미의 원리: 적 무리로 커서 원 이동 → 소환수가 자율 접근·공격 → 처치 즉시 골드 → 상점에서 기존 공격 진화 또는 새 정령 선택 → 다음 30초에 공격 장면·처리 분포 변화 확인. 수동 스킬·원소 상성표·원소 게이지 없이도 성장 전후가 읽히는지를 먼저 본다. 역할 조합 이해를 필수 재미로 강요하지 않으며 단순 화력·시각 만족도 유효하다.

핵심 위험: 다섯 색의 탄만 늘면 외형 교체에 그친다. 반대로 반응·빙결·장판까지 넣으면 작은 성장 게임보다 설명과 구현 비용이 커진다. 커서를 급히 옮기면 비행 중 공격이 취소되는 공통 규칙 때문에 연쇄/폭발의 기대가 무너질 수 있다.

가장 싼 검증: 같은 적 배치에 단일 탄/폭발/연쇄 결과를 그린 전후 카드로 변화와 다음 구매 이유를 설명하게 하는 실험 설계부터 사용한다. 아직 실행하지 않았다. 시각적인 아름다움·명중감·20분 반복성은 종이 설명만으로 입증하지 않는다.

## 2. 공통 경계와 정령 고유 기제

### 2.1 승인 기준과 상세 제안 구분

[G1] 골드는 드랍 시 즉시 기본 자동 지급, 커서 공격 지정 범위 안의 몬스터만 공격, 지정 범위 확대 업그레이드 존재, 초기 전투 30초 고정, 시간 증가 보류, 무료·무패널티 보스 실패/재도전과 재도전 HP 초기화, 무한 성장·환생 제외. 성장·시각 만족 우선이며 단순 화력 보스 허용.

[원안 상세화/제안] 기본 불씨 1마리. 무피격 유지로 아군 HP·치유·희생 없음. 직업은 런 안에서 유지. 구매·진화·잔액은 다음 턴에도 유지하고 위치·표적·쿨다운·투사체는 종료 때 초기화. 무료 재도전이 임시 강화 누적을 뜻하지 않는다. 보스 해금·보상·시간 상세는 P1-13 소관이며 이 문서는 새로 확정하지 않는다.

05 §B04~B08·§4를 공통 초안으로 그대로 적용한다:
- command_radius=R_cmd는 커서 중심의 지정 반경, attack_range=R_reach는 소환수-적 사거리, effect_radius=R_fx는 공격 효과 형상이다. 골드 수집 반경은 없다.
- 현재 원 안 기존 표적 유지, 없으면 소환수에서 최근접 적·ID 동률 순. 원 밖 자동 대체 공격 없음. 사거리 밖이면 자율 접근, 빈 원에서는 대기.
- 발사 전 자격 확인, 비행 중 지정 이탈 시 즉시 무효화, 재진입해도 옛 투사체 복원 금지. 발사 뒤 사거리 이탈만으로는 취소하지 않는다. 소비한 쿨다운 환불 없음.
- 폭발·연쇄·부가 피해도 매 피해 시점 현재 지정 범위 안 적만 타격. 주대상 무효면 폭발 없음. 한 공격ID로 같은 적을 두 번 때리지 않는다.
- 효과는 추가 기본 공격을 재귀 생성하지 않는다. 정령별 특수 표적 선정·장판·도트 예외 없음. 정확히 종료 시각의 타격은 무효이며 유효 사망만 1회 지급.
이 경계는 대표가 별도로 승인한 세부 명세가 아니라 후속 공통 초안이다. 완화가 필요하면 05와 함께 검토하고 핵심 방향 변경은 대표 재확인한다.

### 2.2 정령만의 기제 [제안]

고유 기제는 ‘공격 형태 포트폴리오’: 불씨는 밀집 폭발, 번개는 떨어진 적 연결, 물결은 반복 단일 타격, 바위는 느린 고위력 타격, 광휘는 밀집 마무리를 담당한다. 원소 이름은 공격 형태 태그일 뿐 적 약점·상태이상·속성 반응을 만들지 않는다. 같은 대상에 불과 물이 맞아도 별도 반응 없음.

종마다 1마리만 영구 보유, 확장 전체 permanent_cap=5, temporary_cap=0(기획 가정, 성능 실측 아님). 계약은 해당 종 1마리를 다음 전투부터 추가하며 교체/소환 슬롯 UI 없음. 진화는 기존 개체 stage를 바꾸며 추가 종/개체로 세지 않는다. 별도 궁극기 입력·쿨타임 게이지 없음.

다른 직업과의 차이: 용의 단일 주력 대형화/교체 후보와 달리 정령은 서로 다른 분포의 자동 공격을 동시에 추가한다. 동물의 다수 동일종 증식, 악마의 적별 표식 소비, 네크로의 처치 기반 턴 내부 증식은 사용하지 않는다. 그러나 표적 공유·과잉 피해가 심하면 이 차이가 실제 만족으로 이어지지 않을 수 있다.

## 3. 소환수 5종·진화·공격 데이터 [확장 후보]

아래 모든 수치·상한은 비교용 가정이며 밸런스 승인/실측이 아니다. distance는 05의 전장 논리 단위. 모든 소환수 class_id=CLS_ELM, persistence=run, slot_cost=1, target_policy=cursor_eligible_only, 진화 전 stage_id=BASE. 기본 불씨만 initial_count=1, 나머지 initial_count=0. 전투 생성·이동·정렬은 05 B01/B03/B09 사용.

공통 공격 가정: 준비(windup)=0.2초, 표의 CD는 발사 뒤 다음 준비까지의 쿨다운으로 interval_s와 같지 않다. 정지·무중단 시 최소 발사 간격 interval_s=windup+CD. 탄 속도=600, 수명=2초는 05 예시를 사용. 이동/무효화로 실제 타격 간격은 늘어난다. 피해는 방어·치명타 없는 비교 단위, 기본 attacks는 원거리 추적탄이며 근접 충돌 아님.

폭발 대상이 상한을 넘으면 주대상 우선, 이후 폭발 중심에서 가까운 적·ID 순. 번개 연결은 주대상 명중 사건 안에서 순차 판정하고 각 연결마다 현재 자격을 검사한다(연결 지연 없음 제안). 연쇄의 effect_radius는 연결 1회당 거리이며 지정 반경을 뜻하지 않는다. 피해 감쇠는 초기 제안에서 없고, 추가 연결이 같은 보스를 다시 때리지 않는다.

물결은 진화해도 single로 유지한다. 모든 진화가 새 판정이어야 할 필요는 없다. 공격 형태 변화는 불씨·번개·바위·광휘에서 제공하며 물결까지 부채꼴/빙결로 확장하지 않는다. 수치 진화만으로 보상이 부족하면 물결 자체를 먼저 보류한다.

## 4. 전용 업그레이드 카탈로그 — 필수 10필드+유형

모든 행은 06 §4.4와 동일 계약이다. 공통 필드(각 행에 적용): category=summon, applies_to=CLS_ELM, unlock_condition=run_start(추가 턴/보스/몬스터 진행 조건 없음), status=proposed, source_ref=source §4·§5 및 P1-07. 구매 가능 조건은 이 해금 조건 AND 표의 prerequisites AND 충분한 골드 AND 현재 레벨<max_level이다. 모든 선행은 AND, 없음은 []. 상점에서 직접 구매하며 효과는 다음 전투 준비에 복원한다.

cost={currency:gold, base:null, growth_rule:null, rounding:null, status:미정-P1-12/14 통합 대기}. 모든 행에 이 비용 객체를 명시 적용한다. 단발은 최초 비용만 미정이고 증가 없음(growth_rule=one_shot), 반복형 최초 비용·증가식·반올림은 미정이다. 미정은 무료 또는 0원이 아니다. 이 문서의 경로 검증은 조건 도달성만 검사하며 실제 구매 속도는 주장하지 않는다.

전용 레코드 수량에는 UPG_COM_COMMAND_RADIUS를 넣지 않는다. 공통 반경 확대는 06의 ID를 그대로 인용하며 레벨·값·비용은 12/14 통합 대기다. 수집 반경이나 사거리로 이름을 바꾸지 않는다. 이 카드는 공통 업그레이드 수치를 중복 소유하지 않는다.

각 EFF는 지속 구매 상태를 읽어 위 필드를 설정/가산하며 생성·소비 자원 없음, run 초기화, cap은 max_level 또는 표의 유한 대상/개체 수, can_trigger_other_effects=false, reward_policy=no_extra_gold. 계약 EFF는 전투마다 기존 소유 1개체를 복원할 뿐 턴마다 누적 증식하지 않는다. 진화로 피해 중복 판정을 추가하지 않는다. DUET은 적 상태를 소비하지 않는 보유 시너지여서 악마 표식과 다르다. 조건 조회는 전투 준비 시 한 번으로 충분하다는 요구 제안이며 구현 방식 지정 아님.

## 5. 성장 트리·대표 빌드 2종

트리 표기는 레벨 조건이며 화살표는 필요조건, 합류는 AND다. 분기 간 배타 잠금 없음. 아래는 구매 우선순위 빌드이며 영구 불가역 직업 분화가 아니다. 나중에 둘 다 살 수 있어 최종에는 수렴한다. 이를 장기 리플레이성을 보장하는 독립 빌드로 과장하지 않는다.

    런 시작 / 불씨1
      ├─ UPG_ELM_POWER (최대3)
      ├─ UPG_ELM_BLOOM(1) ── UPG_ELM_SPLASH(최대2)
      │        └──────────────┐
      ├─ UPG_ELM_TIDE(1) ── UPG_ELM_TIDE_WAVE(1) ── AND → UPG_ELM_DUET(1)
      ├─ UPG_ELM_SPARK(1) ── UPG_ELM_TEMPO(최대2)
      │        └─ UPG_ELM_SPARK_ARC(1) + BLOOM(1) → UPG_ELM_PRISM(1) → UPG_ELM_PRISM_CROWN(1)
      └─ UPG_ELM_STONE(1) ── UPG_ELM_STONE_MONOLITH(1)

### 빌드 A: 개화 중심 — 뭉친 적부터 처리

구매 경로(동일 ID 재등장은 다음 레벨): UPG_ELM_BLOOM → UPG_ELM_SPLASH → UPG_ELM_POWER → UPG_ELM_TIDE → UPG_ELM_TIDE_WAVE → UPG_ELM_DUET → UPG_ELM_SPLASH → UPG_ELM_POWER → UPG_ELM_POWER.

도달 형태: 불씨 BLOOM+POWER3+SPLASH2+DUET1, 물결 WAVE. 유한 2개체. 불씨 피해는 공통 버프 제외 19, R_fx=80, 최대3대상. 물결은 피해8 단일. 모두 현재 지정 범위 안에서만 유효.

장점: 첫 진화로 단일→폭발 변화가 빨리 읽히며 좁은 무리 대상으로 원을 오래 두기 좋다. 단점: 최대3대상 상한, 원 밖 폭발 손실, 흩어진 적을 연결하지 못함. 단일 보스에 폭발 반경은 피해 배수가 아니다. 다음 목표는 번개를 더해 분산 처리 보완. 가격 미정으로 ‘몇 턴 안 완성’은 주장하지 않음.

예상 플레이 예시(실제 기록 아님): 한 원 안 밀집 적3개를 불씨 폭발로 함께 타격한다. 커서를 오른쪽으로 옮기기 전 탄의 명중을 기다릴 이유가 생기지만 빠른 조작을 강요하는 목표는 아니다. 물결은 살아남은 단일 적에 계속 공격할 수 있으나 공통 표적 공유 때문에 반드시 분산한다고 보장하지 않는다.

### 빌드 B: 연쇄 확장 — 흩어진 적 연결

구매 경로: UPG_ELM_SPARK → UPG_ELM_TEMPO → UPG_ELM_SPARK_ARC → UPG_ELM_BLOOM → UPG_ELM_PRISM → UPG_ELM_PRISM_CROWN → UPG_ELM_TEMPO → UPG_ELM_STONE → UPG_ELM_STONE_MONOLITH.

도달 형태: 불씨 BLOOM, 번개 ARC+TEMPO2, 바위 MONOLITH, 광휘 CROWN. 유한 4개체. 번개는 CD=1.2초·최소 간격1.4초, 최대4대상, 연결거리100. 광휘 R_fx=90·최대4대상.

장점: 한 폭발 안에 다 안 들어와도 연결거리 내 이웃 적을 처리할 기회, 개체 실루엣과 탄도 증가가 분명함. 단점: 넓은 지정 원을 확보하지 못하면 연결 수를 못 채움. 큰 원도 공격 사거리/이동 지연을 해결하지 않음. 단일 보스에 연쇄 재타격이 없어 추가 연결 구매 효율 낮음. 다음 목표는 물결 또는 불씨 화력 강화.

예상 플레이 예시: 같은 원 안 적들이 폭발 반경 밖이되 연결거리 안에 있다면 번개가 최대4개체까지 이어진다. 둘째 적이 원 밖이면 그 적을 건너뛰고 자격 있는 다른 적을 찾으며 없으면 종료. 전장 전체를 찾아 연쇄를 완성하지 않는다.

### 최종 성장 형태 [확장 종착점 제안]

불씨 BLOOM, 번개 ARC, 물결 WAVE, 바위 MONOLITH, 광휘 CROWN의 5개체와 전용 업그레이드의 유한 최대 레벨. 화면의 보상은 서로 다른 실루엣·단일 탄·폭발 고리·연쇄선의 합주다. 이름 ‘오원소 군단’은 설명용, 여섯 번째 소환수/궁극기/합체 규칙이 아니다. 전체 최종화는 보스 해금의 필수 조건으로 지정하지 않는다(P1-13 결정 대기). 모든 최종 투자가 보스 단일 DPS에 같은 효율일 필요는 없지만 잘못 산 광역 때문에 필수 재시작하는 상태는 14/15에서 검사해야 한다. 클리어 후 통계→메인, 무한 강화 없음.

## 8. 검증 설계·위험·미해결

핵심 가설 H1: 같은 장면에서 개화/번개 구매 뒤 ‘더 세졌다’ 또는 ‘맞는 적 분포가 달라졌다’를 스스로 알아보고 다음 구매를 기대한다. 복잡한 역할 이해를 필수로 요구하지 않는다.
H2: 원 안 지정·골드 자동 지급을 이해하며, 손이 바쁘지 않아도 공격을 구경하는 시간이 지루하지 않다.

## 1. 추천·재미 가설·핵심 위험

추천 한 줄: 약한 몬스터 공급을 끝까지 남기고 유한한 필수 성장 뒤 선택 도전하는 단일 보스로 군단의 화력과 달라진 공격 장면을 확인한 후 통계로 끝낸다.

재미의 원리: 무리 지정 → 처치 즉시 골드 → 수량·공격 형태·지정 반경 투자 → 더 넓고 화려한 처치 → 보스 HP 감소에서 성장 확인. 기믹을 이해하거나 모든 조합을 완성하는 능력을 필수 시험으로 삼지 않는다.

핵심 위험: 단일 보스는 광역/처치 증식 투자 효율이 낮다. 최종 성장에서도 제한시간 내 처치가 불가능하면 유한 성장 때문에 영구 막힘이 된다. 해법은 잡몹·방어체·피격을 즉시 추가하는 것이 아니라 직업별 기본 단일 피해 검증과 고정 보스 HP 조정부터 비교하는 것이다.

가장 싼 검증: 구매 전후 전장 그림과 보스 HP 사건표, 실패→상점→일반전/재도전 경로를 문서로 추적한다. 실제 화려함·반복 재미는 여기서 입증할 수 없으며 승인 후 별도 테스트가 필요하다.

### 1.1 불변 기준과 제안의 경계

- [G1] 드랍 즉시 자동 골드 지급, 커서 지정 범위 안 몬스터 공격, 공격 지정 반경 확대, 성장·시각 만족 우선, 단순 화력 보스 허용.
- [G1] 초기 전투 30초 고정, 시간 증가 보류. 일반전 30초를 유지하며 보스도 별도 시간이 승인되지 않았으므로 초기 비교안 T_boss=30초로 제안한다. 보스 시간 자체의 별도 확정으로 확대하지 않는다.
- [G1] 입장료·실패 패널티·재도전 비용 없음, 재도전 보스 최대 HP로 초기화. 무한 성장·환생 제외, 최종 처치 뒤 통계→메인.
- [원안 유지 상세화] 소환수 무피격. 아군 HP·사망·치유·접촉 피해 없음. 보스 공격 시스템 전부가 대표에게 별도 승인된 것은 아니다.
- [공통 초안 인용] 05 §9.4의 R_cmd/사거리/효과 반경 분리, 현재 지정 자격 검사, 비행 중 이탈 즉시 무효·재진입 복원 금지. 본 문서에서 직업·보스 예외를 만들지 않는다.
- [제안] 이하 표의 모든 숫자는 가정값, 성능 상한은 실측 보장 아님. 첫 직업·콘텐츠 수량·MVP·플랫폼·엔진·가격은 확정하지 않는다.

## 2. 일반 몬스터 데이터와 공급

### 2.1 몬스터 정의 [제안/가정]

좌표 단위는 05와 같은 L=1000 정사각형 전장 단위다. 크기는 표시 반지름이며 타깃 지정은 그림 겹침이 아닌 중심 좌표로 판정한다. 이동은 직선 배회·경계 반사, 소환수 추격/공격/밀어내기 없음. 속도는 전장 단위/초. 아래 골드는 기본 정수 보상이며 추가 배수/반올림 정책은 P1-14가 별도 명시해야 한다.

| ID | 이름·역할 | 최대 HP | 기본 골드 | 표시 반지름 | 이동 속도 | 해금 | 구분·시각 정보 |
|---|---|---:|---:|---:|---:|---|---|
| MON_BASIC | 작은 잔영 / 초기 처치 대상 | 10 | 1 | 18 | 40 | 런 시작 | 일반. 둥근 작은 실루엣 |
| MON_DENSE | 묵직한 잔영 / 오래 때리는 대상 | 30 | 3 | 28 | 25 | 공급 단계 s≥1 | 일반. 넓은 사각 실루엣·HP 표시 |
| MON_SPECIAL | 황금 잔영 / 유한 보너스 표적 | 40 | 6 | 24 | 35 | 공급 단계 s=2, 매 일반전 15초 예약 1회 | 특수. 별 모양 윤곽, 색 외 표시. 도망·제한 수명 없음 |

두 일반종+특수 변형은 제작 범위 제안이다. 특수종은 새로운 AI 대신 HP/보상·실루엣 차이만 사용한다. 비용이 크면 일반 2종+보스만 남기고 특수 예약과 보상을 같이 제거한다. 이는 MVP 선택안이지 삭제 승인 아님.

HP/골드는 구매나 턴 횟수에 따라 자동 인플레이션하지 않는다. 강해진 적은 해당 종류 고정값을 쓴다. 첫 버전은 방어력·속성 저항·회피·무적·회복·소환수 피해를 넣지 않는다. HP/골드 비율만으로 경제 균형이 맞는다고 판단하지 않는다. 접근·과잉 공격·대상 이탈이 처치 수에 영향을 준다.

### 2.2 유한 스폰 표 [제안/가정]

공급 단계 s∈{0,1,2}. 초기 s=0. 몬스터 공급/종류 업그레이드에 의해 다음 전투부터 s=1,2가 해금되는 비교안이다. 실제 구매 ID·선행·비용·최대 레벨은 P1-12가 정의하고 P1-14가 경제에 연결한다. 아래 s는 데이터 상태값이며 새 업그레이드 ID를 선점하지 않는다. s는 턴 횟수나 보스 실패 횟수로 오르지 않는다.

| 공급 단계 | 예약 시각(초) | 매 예약 MON_BASIC | 매 예약 MON_DENSE | MON_SPECIAL 추가 예약 | 동시 생존 상한 | 전투당 예약 공급 상한 |
|---|---|---:|---:|---|---:|---:|
| s=0 | 0,5,10,15,20,25 | 4 | 0 | 없음 | 48 | 24 |
| s=1 | 0,5,10,15,20,25 | 4 | 2 | 없음 | 48 | 36 |
| s=2 | 0,5,10,15,20,25 | 4 | 4 | 15초 1마리 | 48 | 49 |

일반 예약은 BASIC→DENSE 순서, 같은 시각 특수는 일반 묶음 뒤 생성한다. 따라서 상한으로 특수가 누락될 수 있으며 확정 보너스가 아니다. 처치 시 즉시 재충원하지 않는다. 더 빨리 죽여도 예정된 총공급 이상으로 생성되지 않는다. 예비 적 무한 생성·미처리 예약 부채 없음. 정확히 30초 생성 없음.

05 B02의 필드 내부 후보·시드·겹침 제한·슬롯 부족 건너뛰기·스폰 즉시 지정 가능 계약을 인용한다. 위치를 커서 주변으로 몰아주지 않는다. 현재 생존 상한 또는 배치 슬롯 부족이면 해당 개체 예약을 건너뛰고 보상 0. 사망 연출 잔상은 생존 상한에 포함하지 않는다. 종료 청소는 처치/드랍 아님.

전 단계에서 BASIC 예약을 그대로 유지해 고HP 적 해금만으로 초기 수입원을 제거하지 않는다. 단, 강한 적에 대한 과잉 집중·자리 부족으로 실제 BASIC 수입이 감소할 수 있으므로 “수입 감소가 절대 없다”는 보장은 하지 않는다. 일반전을 구매 없이 다시 시작할 수 있고 입장료도 없다. 강한 적 자동 전면 교체안보다 공급 유지안을 권고한다. 공급 단계 선택/환불 UI는 초기안에 추가하지 않는다.

### 2.3 경제에 넘기는 상한과 병목

모든 예약이 생성되고 모두 합법 처치되며 배수/상자 없다는 가정의 기본 골드 상한:
- s=0: BASIC 24마리, 기본 골드 24.
- s=1: BASIC 24+ DENSE 12마리, 기본 골드 60.
- s=2: BASIC 24+ DENSE 24+ SPECIAL 1마리, 기본 골드 102.

이는 실제 예상 수입이 아니라 예약상의 최대다. s=2의 총 예약 49는 동시 생존 상한 48보다 클 수 있으며 처치가 없으면 일부 예약이 누락된다. 공급 상한·동시 상한·처치 수를 혼용하지 않는다. 전투 종료까지 모두 살아 있으면 골드 0이다.

실제 기본 수입 = 해당 전투의 합법 사망별 최종 정수 지급액 합. 수집률·커서 골드 접촉·미수집 손실 계수 없음. 지정 반경은 R_cmd이며 반경 확대를 골드 배수로 직접 환산하지 않는다. 관측 항목은 종류별 예약/생성/상한누락/슬롯누락/처치, 빈 지정 시간, 이탈 무효 공격, 실지급 골드다.

P1-14/15 인계: 공급 단계별 공격력·수량·이동·주기·지정 범위가 처치 한도에 미치는 영향과 다음 구매 대기시간을 계산한다. 비용은 이 문서가 정하지 않는다. 시각 혼잡이나 성능 문제가 있으면 수입을 몰래 깎는 개체 삭제가 아니라 스폰 표·보상·표시를 함께 재검토한다.

## 3. 보스 해금 조건 비교

원문 §9 L361은 모든 필수 업그레이드 완료 시 등장이다. 필수 집합의 구체 목록이 없으므로 “전체 상점 완매”로 확대하면 안 된다.

| 선택 | 장점 | 위험·비용 | 판단 |
|---|---|---|---|
| A 유한 필수 집합 완료 | 성장 종착점 명료, 원안 유지, 필수 진행 표시 단순 | 선택 빌드까지 필수로 묶으면 노동, 필수 가격/선행 순환 시 영구 잠김 | 기본 권고. 직업별 최소 경로만 집합으로 지정 |
| B 중간 마일스톤에서 조기 도전 해금 | 화력 시험을 일찍 할 수 있음, 선택 투자 폭 | 약한 상태 반복 실패·해금/권장전력 안내 추가 | 대안으로 보존, 현재 기본안 아님 |
| C 일정 전투 횟수 자동 등장 | 구매 선택과 독립 | 성장 여부와 무관한 등장, 시간 채우기 유도 | 비권고 |

권고 상세: 직업별 boss_required_set의 각 {upgrade_id, required_level} 충족 시 boss_unlocked=true를 한 번 설정하고 상점의 무료 도전 버튼을 활성화한다. 자동으로 전투를 빼앗거나 강제 입장시키지 않는다. 일반전 버튼은 유지한다. 해금 후 필수 집합 재평가로 다시 잠그지 않는다.

필수 집합 예시 구조는 “직업 기본 전력의 유한 최종 단계 + 대표 성장 해금”이며 정령의 광역과 연쇄를 동시에 무조건 요구하지 않는다. 정확한 ID·레벨 목록은 P1-07~12 및 경제 검토 후 정의한다. 목록 미정인 지금의 데이터는 실행 사양이 아니다. 빈 집합을 참으로 처리해 시작 즉시 보스를 열지 말고, 누락/순환/도달 불가 참조를 문서 승인 전 결함으로 다룬다. 해금 보상 골드는 없다.

A의 변경점은 필수 집합 완료 “강제 등장” 대신 “도전 해금·선택 입장”이다. G1에서 이 버튼/해금은 별도 승인되지 않았으므로 제안으로만 넘긴다. A와 B의 재미를 실제로 비교한 기록은 없다.

## 4. 최종 보스 7항목

### B01 등장 조건 [제안]

BOSS_FINAL 1종, 위 A안의 필수 집합 완료 뒤 상점에서 선택 도전. 준비 화면에 “제한시간 내 처치 / 무료 / 실패 시 성장 유지 / 재도전 HP 초기화” 안내. 준비→시작 때 중앙(500,500)에 1개체 생성, 표시 반지름 90, 이동 속도 0. 일반 몬스터·특수 몬스터·상자 예약 없음. 현재 구매 소환수는 05 생성 규칙대로 복원한다. 준비 중 공격·타이머 진행 없음.

### B02 공격 방식·무피격 유지안 [원안 유지 상세화/제안]

보스의 소환수 대상 피해 공격은 없음. 접촉 피해·넉백·기절·아군 HP·회복 없음. 공격처럼 보이는 장판을 깔고 사실은 피해가 없는 속임수도 쓰지 않는다. 대신 피격 시 표면 균열·맥동과 HP 감소로 “군단이 강한 적을 무너뜨린다”를 전달한다. 보스 가동은 호흡/형태 변화의 비상호작용 연출이지 회피 요구가 아니다.

대안: 소환수를 피격·기절시키는 보스는 긴장감을 줄 수 있지만 무피격 문맥과 경제·AI·UX를 바꾸므로 현안 제외, 대표 재확인 없이는 도입 금지. 방어체/잡몹/페이즈 저항도 초기 필수 아님. 단순 HP 보스를 금지하던 원문보다 최신 G1을 우선한다.

### B03 HP와 난이도 [가정]

비교 시작값 최대 HP=1000, T_boss=30초. 보스는 구매/실패 횟수에 맞춰 HP가 자동 증가하지 않는다. 방어력/회복/무적/저HP 강제 생존 없음. 05의 [0,T)만 유효하며 정확히 T의 마지막 타격은 실패다. T 미만 사망 확정이면 즉시 승리한다.

산술 선별 가정: 접근·준비 손실 2초, 이후 유효 단일 DPS가 일정하면 28초 동안 DPS30은 피해840으로 실패, DPS40은 피해1120으로 처치 가능 후보. HP1000 처치 예상은 전자 약35.33초, 후자27초다. 이는 연속 근사이며 05의 준비/쿨다운·투사체 지연·공격 횟수 이산성·지정 이탈을 반영한 시뮬레이션이 아니다. 정확한 완료 판정은 피해 사건 시각 합계로 계산해야 한다.

P1-14/15는 직업별 필수 완성 상태와 허용 구매 경로에서 유효 피해 총합이 HP를 T 미만에 넘는지, 최종 유한 성장에서 충분한 여유가 있는지 검사한다. 이 조건이 실패하면 보스 HP 하향·영구 기본 전력 보완을 우선 비교한다. 무한 레벨이나 시간 증가로 해결하지 않는다. 현재 HP1000의 적정성·클리어 가능성은 미검증이며 최종 GDD 전 미해결 차단 항목이다.

### B04 소환수 조합과 상호작용 [제안]

보스도 중심이 현재 R_cmd 안일 때만 지정 가능. 큰 그림의 가장자리만 원과 겹치면 공격하지 않는다. R_reach까지 자율 접근해야 한다. 중앙에 원을 유지해도 되는 것을 허용하며 일부러 커서를 계속 움직이게 만드는 기믹을 넣지 않는다. 광역/연쇄가 동일 보스를 다수 대상으로 세어 반복 타격하지 않는다. 05의 attack_id당 같은 적 최대 1회 경계를 유지한다.

| 직업 | 단일 보스에서 유지되는 가치 | 사라지는 이득·영구 막힘 검사 |
|---|---|---|
| 정령 | 단일 기본 탄·각 정령의 주대상 피해 | 주변 광역/연쇄 추가 대상 없음. 다중 적 효율을 단일 DPS로 부풀리지 않음 |
| 용 | 주력 진화의 주대상 피해·보조용 기본 피해 | 넓은 부채꼴 면적만 키우는 투자의 보스 효율 별도 확인 |
| 동물 | 영구 마릿수·허용 보유 조합 보너스 | 겹침은 허용, 같은 보너스 마릿수 중복 금지 |
| 악마 | 보스 1개체에 표식 적용→소비 | 표식 연계 없이도 기본 피해 존재, 원 밖에서는 피해 없음 |
| 네크로 | 영구 해골/리치 기본 피해 | 보스 사망 전 시체 토큰 0·임시 증식 0. 일반전 토큰 반입 금지 |

직업별 필수 완성에서 단일 보스를 못 잡는다면 직업 전력/보스 HP 검토 사유다. 언데드 전용 잡몹 스폰이나 무료 토큰을 자동 추가하지 않는다. 조합 다양성은 선택 성장의 가능성이지 모든 직업·모든 조합 승리를 확인했다는 주장이 아니다.

### B05 실패·재도전 [G1 + 세부 제안]

시간 도달 시 HP>0 또는 정확히 T에 예정된 마지막 타격만 있는 경우 실패 잠금→실패 요약→상점. 입장료 0, 실패 차감 0, 재도전 비용 0. 보유 골드·구매·해금 유지, 디버프/수리/대기 쿨다운/광고 조건 없음. 실패는 자원 손실 패널티가 아니며 사용한 플레이 시간 자체는 환불하지 않는다.

상점은 구매 없이 무료 재도전 또는 일반전 선택 가능. 골드 0이어도 두 선택이 막히지 않는다. 재도전은 새 combat_id, 보스 HP1000으로 완전 초기화. 위치·대상·투사체·표식·시체·임시 소환·일시 효과·전투 쿨다운은 05/06대로 새 전투 시작 상태로 복원한다. 실패한 도전의 누적 피해로 토벌하지 않는다. 보스 실패 시 보상은 0이라는 세부 제안이며 G1 확정 사실로 쓰지 않는다.

### B06 클리어 보상 [제안]

추천은 보스 처치 골드 0, 상자 0, 실패 부분피해 보상 0. 보상은 클리어 상태·구매한 군단의 승리 장면·이번 런 통계다. 종료 뒤 쓸 곳 없는 통화를 추가하지 않고 무료 실패 파밍도 막는다. 이는 일반 몬스터 드랍의 즉시 지급과 다르지 않다. 보스 기본 드랍을 0으로 정하는 제안이다.

대안은 일회 골드/기념 해금 보상이지만 사용처·메인 영구 해금·저장 의존성이 늘어난다. 현 단계 비권고이며 추후 채택 시 별도 데이터와 중복 지급 검사가 필요하다. 보스 클리어 자체를 희귀도 추첨이나 유료 재화로 만들지 않는다.

승리 사건은 combat_id당 단 한 번 확정, run_id의 cleared는 false→true 한 번. 이후 피해·드랍 콜백 무효. 통계 열기/확인/메인 복귀는 보상 사건이 아니다. 저장·재실행까지 보장하는 트랜잭션 구현은 Sam 검토 및 저장 정책 확정 전 미검증이다.

### B07 클리어 연출·종료 [제안]

사망 확정 즉시 타이머/공격/입력을 잠그고 승리 고정 → 보스 균열과 짧은 붕괴 → 소환 군단이 남은 전장 승리 장면 → 통계 → 새로 누른 확인 → 메인. 저비용 후보는 기존 피격 효과·실루엣 축소·밝기 변화 재사용, 새 컷신/카메라 연출/시네마틱 제작 제외다. 번쩍임·화면 흔들림은 낮추거나 생략 가능, 시간 길이와 스킵 버튼 배치는 Mia 검토 대기다.

통계 필수 후보: 선택 직업, 일반전/보스 시도 수, 실제 전투시간, 일반 몬스터 종류별 처치 수, 총지급 골드·총지출·잔액, 주요 구매/진화, 보스 처치 전투의 소환수 구성. 상점 숙고시간은 전투시간과 분리하며 정확한 총소요시간 지표는 P1-14/16에서 정의한다. 수집률·남은 바닥 골드·피격 피해량은 표시하지 않는다.

통계 확인은 메인 이동만 수행한다. 같은 클릭을 새 게임 버튼으로 전달하지 않는다. 보스 재전투·엔딩 후 일반전·환생 버튼 없음. 통계는 잔액을 재가산하지 않는다. 메인 새 게임은 새 런 초기 상태로 시작하는 제안이며 영구 성장 승계가 없다. 영구 기록·이어하기·앱 종료 복구는 별도 저장 정책 미정, 자동 삭제/영구 보존을 약속하지 않는다.

## 6. 상태 전이와 원장 불변식

### 6.1 전체 경로 [세부 제안]

메인 → 새 런/직업 선택 → 일반 준비 → 일반전[0,30) → 종료 잠금 → 정산 표시 → 상점
상점 → 구매/저축 → 일반 준비
상점 + 필수 집합 완료 → 해금 표시 유지 → 보스 도전 선택 → 보스 준비 → 보스전
보스전 + T 미만 HP≤0 → 승리 잠금 → 클리어 연출 → 통계 → 확인 → 메인
보스전 + T 도달(승리 미확정) → 실패 잠금 → 실패 요약 → 상점 → 무료 재도전 / 일반 준비

상점·요약·통계에서 시간은 흐르지 않는다. 앱 포커스 상실/일시정지와 종료 동시 사건 순서는 05 §3~4를 인용한다. 결과 화면으로 들어오던 클릭은 폐기한다. 실패 요약은 비용 없이 상점으로 진행 가능하며 모달 때문에 일반전/재도전 선택이 영구 잠기지 않아야 한다.

### 6.2 불변식

- 잔액 = 시작 잔액 + 일반전의 합법 즉시 지급 합 - 유효 구매 차감 합. 이 문서 제안에서 보스 관련 수입/차감 모두 0.
- 사망 보상 키는 05의 combat_id+entity_id, 별도 06의 battle_id/death_event_id 기록과 같은 사건을 참조한다. 동일 보상을 두 키 체계로 각각 지급하지 않는다.
- 종료 청소·강제 경계 복구·요약 화면 진입·해금 통보·보스 부분피해·재도전은 드랍 사건 아님.
- 상점 정산은 표시, 재지급 아님. 무료 재도전을 누를수록 돈이나 영구 전력이 늘어나지 않는다.
- 전투의 HP/표식/토큰/임시 개체는 전투별, 구매/잔액/해금은 런별. 메인 영구 저장과 혼용하지 않는다.
- 살아 있는 강한 몬스터는 다음 일반전에 이월되지 않으며 보스 실패 HP도 이월되지 않는다.

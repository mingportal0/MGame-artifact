# D01 문서 작성 승인 범위 — 공개 요약

결정ID: D-20261026-D01-EXECUTION / 일자: 2026-10-26 KST / 기록: Sophie
상태: D01 문서 작성만 승인. 아래 범위를 넘어선 개발 승인이 아니다.

대표는 D01 데모 범위·개발 승인 패키지 작성을 승인했다. 적 수 증가·새로운 적 해금·확률형 엘리트 출현은 모두 구매 가능한 독립 업그레이드이며, 구매가 금화 보상 증가에 대한 기대와 연결되어야 한다. 공급 증가·처치 가능량·실제 획득 금화를 구별하고 구매 전 효과·기대·위험을 보여준다. 구체 가격·확률·수치는 전문가 제안이지 대표 확정값이 아니다.

Sophie가 취합하고 James는 규칙·경제, Mia는 최소 표시, Sam은 기술 후보·시험 기준을 제안한다. [D01 패키지](artifacts/D01.md)와 [실제 자문·검증](artifacts/D01-evidence.md)은 대표 판단을 돕는 검토 자료다. 내부 승인 원문은 공유 정본의 결정 기록에 보존하며 이 공개본은 대화 식별자·개인 식별정보를 제외한 요약이다.

데모 축소 수량·기술 선택·G3 게임 코드 개발·프로젝트 초기화·외부 게임 배포는 미승인이다. 전체 최소100개 정도 목표와 일반적4종 요구는 자동 폐기하지 않는다. D02/D03 및 기존 R03~R15는 별도 명시 승인 전 실행하지 않는다. 이번 배포는 기존 검토 저장소의 승인된 문서 공유 범위이며 신규 게임 배포 승인이 아니다. 완료 알림·커밋·푸시는 다음 카드 실행 허가가 아니다.

# F07 정령 분산·공격 우선 구현 요약

문서ID: P1-F07-TECH-v01 / 담당: Sam
범위: 승인된 F07 최소 구현과 격리 기능 검증. 사람 플레이·최종 밸런스·전체 데모 인수 완료본은 아니다.

## 적용한 규칙
- 커서 범위 안에서 지금 공격 가능한 적을 먼저 공격한다. 없으면 범위 안 적을 향해 접근하며, 접근 중 사거리 안 외부 적에 대한 기존 자동 사격은 허용한다. 접근 표적 기억은 외부 사격으로 지워지지 않는다.
- 실제 정령-적 거리 3을 최대 공격거리로 사용한다. 최대거리 위치는 선호 목표이며, 이미 사거리 안이면 배치 완료를 기다리지 않고 기존 쿨다운에 맞춰 사격한다. 경계·간격 제약에서는 더 가까운 유효 사격을 허용한다.
- 실제 커서 중심 보존, 화면 안 표시, 종류별 간격을 적용한다. 유효 원호와 안쪽 압축을 결정적인 유한 후보 탐색으로 처리한다. 이동 중 교차는 정지 후 분리와 구분하며 새 경로탐색이나 역할 AI를 만들지 않았다.
- U05는 지휘 반경 2→2.5와 배치 목표거리를 연동한다. 정령 공격거리·피해·주기·가격·보상·전용 해금·효과·전멸 종료 규칙은 보존했다.

## 실제 실행 근거
- Unity 6000.6.7f1의 승인 격리 Windows 환경에서 실행했다. 원본 보호 대상 75파일의 변경 없음과 보존 소스·격리 소스·내부 프로젝트의 일치를 확인했다.
- TC01~12를 포함한 내부 기능 18개 검사, 정확한 공격·지휘 경계, 표적 소멸, 접근 중 외부 사격, 쿨다운 이동, 모서리, 정지·재개를 검사했다.
- 최종 Windows 빌드 출력, 독립 전달폴더, 실제 ZIP 재추출 실행은 각각 335/335·실패0·exit0이다. 마감 독립 전달물 재실행도335/335·exit0으로 확인했다. 같은 시험의 반복 실행을 고유 시험 수로 합산하지 않는다. 상세 NUnit/식별 결과는 F07-validation-summary.json에 분리한다.
- 화면 5해상도×한/영×중앙/4모서리의 50패널을 측정했다. 지원 30패널은 안정배치/토큰 경계/간격/적 겹침/발사선 좌표를 검사했고, 작은 화면 20패널은 명시적 미지원으로 분리했다.
- 실제 UI 콜백 자연경로는 신규 0G에서 3전투 수입77G, U01/S01/S02 지출70G, 잔액7G, 다음 전투 3종 생성까지 확인했다. 주입금/직접 피해 호출 없이 실행했다. 실제 물리 마우스 검증은 아니다.

## 동일 입력 경제 진단
F06 완료판과 F07을 288쌍 비교했다. 시드100~102, 1/2/3종, U05 OFF/ON, 시너지 OFF/ON, 적 투자 8설정을 조합했다. F06이 생성한 고정틱 커서 입력을 F07에 그대로 재생했으며, F06 조기 종료 이후에는 마지막 커서를 유지했다. 후보판을 보아 커서를 다시 정하지 않았다.

불변식 실패는0이다. 96그룹 중 시간당 수입 변화 검토선에 해당하는 것은10그룹이며, 개별20% 초과는50쌍이다. 최악 단발 G/활동초 변화는 -64.437%다. 같은30G여도 521→1116틱으로 종료가 늦어지는 사례가 있다. 고정 커서의 긴 꼬리와 종료 전 효과/표적 변화가 함께 작용하므로 경제 동등이나 사람 플레이 손실률로 일반화하지 않는다.

James의 실제 독립 검토는 이 진단 범위의 표적·경제 결과를 수용했고 필수 피해/주기/보상/가격 보정은 요구하지 않았다. 별도 0G 모델 경로는 양쪽 모두 같은 구매 라운드에 S01/S02에 도달했다. 다음 3종 전투까지 포함한 활동틱은 5493→5543, 총지출70G, 잔액40→38이었다. 실시간 UI 경로와 이 모델 대조의 종료 범위를 혼합하지 않는다.

## 알려진 한계와 보존한 실패
- 작은 화면에서는 상점을 유지하되 전투 시작을 차단한다. 진행 중 축소는 일시정지, 확대 후에도 명시 재개가 필요하다. 현재 검증 권장 창 크기는1280×720 이상이다. 실제 전장 치수 조건을 쓰므로 모든 DPI를 보장하지 않는다.
- 이동 전체 무겹침, 모든 적 밀도의 안전 배치, 유한 탐색의 수학적 전역 최적성은 주장하지 않는다.
- 최초 좁은 화면 실패, Editor 소형 뷰 fixture의 시작 차단, 정지 적 fixture가 얼음 둔화로 움직인 검증 공백, 잔류 발사선까지 포함한 잘못된 개수 검사는 각각 보존·원인 수정·재시험했다. 최종 성공으로 최초 기록을 덮지 않았다.
- 사람의 지휘 이해·시너지 체감·장기 반복 동기, 물리 입력/OS 포커스/전 DPI, 합의 성능·확률·독립 기술 인수 및 D02/F08 전체 인수는 남아 있다.

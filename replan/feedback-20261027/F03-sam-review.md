## 3. 경계 최소 해법 — 조건부, 개별 clamp에는 반대

### 3.1 표시 안전영역과 실제 간격
실제 전장 내부의 사용 가능한 패널 폭 W, 높이 H를 사용한다. 전체 창 크기로 대신하지 않는다. 48×34가 UI 논리 px인지 패널 스케일 적용 후 크기인지 먼저 맞춘다. 그림자/테두리 여유가 필요하면 Mia 확인 후 여백에 포함한다.
월드 x[-8,8], y[-4,4] 기준 중심 안전영역은 다음과 같다.
- x: [-8 + 16×24/W, 8 - 16×24/W]
- y: [-4 + 8×17/H, 4 - 8×17/H]
W/H가 유효하지 않거나 토큰을 담지 못하면 배치 성공 처리하지 않는다.

두 토큰의 8px 빈틈을 축 정렬 사각형의 분리 기준으로 정의한다면, 화면 중심 차이가 |dx|≥48+8 또는 |dy|≥34+8이어야 한다. 이는 보수적인 축 방향 분리 정의이며 Mia가 요구한 '8px'의 최종 의미와 같다고 단정하지 않는다. 월드 중심 거리1만으로는 이 조건이 보장되지 않는다. 중앙 120도 간격의 현 길이는 식 R×sqrt(3)이며 화면 종횡비까지 반영해야 한다. 이번에 수치 평가를 실행하지 않았다.

### 3.2 추천하는 작은 결정적 슬롯 절차
- 중앙에서 세 Kind의 원래 각도90/210/330 및 고정 대응을 먼저 평가한다. 해금마다 기존 Kind를 재분배하지 않는다.
- 실패 시 C는 그대로 둔다. 원과 안전 직사각형의 교차점으로 유효 원호 구간을 만들고, 원호 끝점에는 필요한 표시 간격을 확보한다. 각 토큰 좌표를 독립 clamp하지 않는다.
- 구현 단순화 후보: 원호 끝점과 일정 각도 격자의 후보만 사용해 최대3자리 조합을 열거한다. 안전영역·투영된 사각형 간격·종류의 원주 순서를 검사하고, 원래 각도 이탈이 작은 조합을 고른다. 동률은 고정 각도/Kind 순으로 해소한다. 난수·프레임시간·Dictionary 순서에 의존하지 않는다. 후보 격자 간격은 F07에서 검사 비용/누락을 보고 정할 구현 세부이지 여기서 승인한 수치가 아니다.
- 반경 R에서 조합을 찾지 못할 때만 사전에 정한 감소 반경 목록을 큰 순서부터 평가한다. 0으로 수렴시켜 겹친 결과를 반환하지 않는다. 원호가 여럿이면 어느 구간에 배치했는지 기록하고 종류 순서를 유지한다. 유한 후보 검사 실패는 수학적으로 배치 불가능하다는 증명이 아니다.
- 가능한 조합이 없으면 명시적인 '이 패널 크기에서 수용 불가'로 판정한다. 가장 작은 지원 창/패널 크기를 Mia와 정하고 좁은 창을 제한하는 대안이 새 경로탐색보다 작다. 토큰 축소·겹침 허용·커서 중심 이동을 몰래 적용하지 않는다.
- 진동이 관측되면 먼저 동일 점수에서 이전 유효 배치 유지와 작은 고정 여유폭을 사용한다. 과거 배치를 사용할 경우 그것도 재생 상태에 포함한다. 임의 자동회전/Kind 교환으로 숨기지 않는다.

### 3.3 결정성·크기 변경·이동의 한계
패널 크기가 배치 논리에 영향을 주면 같은 시드/커서 입력만으로 같은 결과가 보장되지 않는다. 안전영역과 크기 변경 이벤트를 입력으로 기록하고, 비교 시험은 동일 패널 크기·동일 고정틱 이벤트를 사용한다. 모델이 매 프레임 UI 값을 직접 읽는 구조는 피하고 유효한 레이아웃 값만 명시적으로 전달한다. 지원 크기 변경 시 현재 위치가 새 안전영역 밖이면 평상시 추종만으로 즉시 온전한 표시를 보장할 수 없다. 최소 대안은 전투 중 크기 고정, 또는 크기 변경 시 명시 정지 후 재검증이다. 어느 쪽이든 사용자 경험 변경이므로 Mia/James와 확인하며 이번에 채택하지 않았다.

안전영역 안 시작점과 목표 사이 직선 추종은 직사각형 안을 벗어나지 않지만, 개체 사이의 비충돌까지 보장하지는 않는다. 속도6 유지, 실제 위치에서 공격, 경로 교차 시간/최소 화면 간격 기록을 권고한다. 시작 위치가 현재처럼 중앙에 모인 상태, 커서 비활성 시작, 반대편 급이동, 경계 진입/복귀는 별도 사례다. '도착 후 정지 슬롯 분리'와 '이동 전 구간 무겹침'을 동일 완료조건으로 쓰지 않는다. 목표가 겹치지 않는다는 이유로 시작/이동 UI가 통과했다고 말하지 않는다.
최소 검증: R 전후·1/2/3종·중앙/변/모서리·시작 비활성·대각 급이동·해금 직후·크기 변경. 실제 토큰 사각형을 표시하고 정지/이동 결과 분리.
중단: 정지 슬롯 잘림/겹침, 숨은 지휘중심 보정, 종류 뒤바뀜/경계 진동, 지원 크기에서 후보 실패, 또는 새 경로탐색이 필요한 요구. 이동 교차 허용 한계는 Mia 실제 응답 전 미합의다.

## 4. 타깃·경제 보존 — 수용: 선택 알고리즘은 보존, 결과 동일은 보장하지 않음

기존 fallback은 보존한다. 원주 배치로 표적 위치가 달라져 선택 결과가 달라지는 것은 예상 영향이며 fallback 삭제로 교정하지 않는다. 다음 사례를 거리 경계 안/같음/밖으로 나눠 기능 시험한다.
- 사거리 후보 없음, 지휘원 내부 후보 없음/있음, 이전 표적이 내부/외부인 경우.
- 이전 표적이 죽거나 사거리에서 이탈, 같은 거리 ID 동률, 지휘 비활성 자동공격.
- 지휘원 내부 적이 존재해도 해당 정령 사거리 밖인 경우: 내부 우선 조건이 잘못 발동하지 않아야 한다.
공격거리3/속도6/주기·피해·즉시 지급/효과반경은 유지한다. 범위3은 정령의 기본 표적 사거리다. 화염 확산·파쇄·번개 연쇄의 2차 적 도달을 모두 커서 R+3으로 제한하는 새 규칙을 넣지 않는다.

기본 공격의 기하학적 외곽 상한은 R+3이다(정지 목표 기준). 이는 실제 위치가 목표에 도착했을 때의 방향별 가능성이지 전방위 공격 보장이나 경제 실측이 아니다. 원주 중심부 공백, 이동 중 공격 공백, 원 밖 fallback 처치, 얼음과 화염 표적 분리로 파쇄 감소, 연쇄 후보 변화가 가능하다. U05는 지휘원 내부 후보 우선 범위도 바꾸므로 '배치 반경만 바뀜'으로 해석하지 않는다.
최소 검증: 피해/효과/지급 기능 회귀와 배치별 공격 공백·표적별 피해·둔화/파쇄/연쇄·처치G를 함께 비교.
중단: 효과 누락·중복 지급·사거리 밖 기본 공격·공격선과 논리 위치 불일치·화염 기본 반복 무수입. 경제 변화를 피해/보상 자동 조정으로 은폐하지 않는다.

## 5. 동일 종료판 자연경제 회귀 — 조건부 수용, 이번 실행 안 함

F04 및 F06 완료본에서 A만 추가한 변형과 같은 완료본의 기존 오프셋 대조군을 만든다. 과거30초 고정판 대 A+조기종료판을 배치 효과 비교로 혼합하지 않는다. 현재 F04 blocked 기록은 시험 준비 의존성이지 자문 작성 차단 사유는 아니다.

시험 입력에 시드100/101/102, 틱별 커서좌표·활성/정지/재개, 패널 크기/크기변경, 보유/해금 상태, 투자 ON/OFF, 종료규칙·실행 소스 지문을 포함한다. 실시간 사람 마우스를 두 번 흉내 내는 방식 대신 고정틱 재생 입력을 쓴다. 같은 변형 재실행 로그가 같아야 결정성 통과다. A와 대조군의 피해 로그가 같아야 한다는 뜻은 아니다.

1. 기능 진단 상태: 화염만/화염+얼음/3종, U05 전후, 각 효과 단독 및 파쇄·연쇄 조합. 투자0~7은 확장 진단으로 사용. 주입 상태 시험은 자연수입 증거와 분리한다.
2. 자연 경로: 새 게임0G·화염만·투자 모두 OFF. 직접 Hit/초기 주입금 없이 실제 자동 공격→무료 반복→S01→S02. 소환 우선 경로와 U01 먼저 구매 경로를 별도 기록. S01/S02 가격은 F01의 시험제안이며 F06 실제 채택값을 기준으로 한다.
3. 두 종류 비교를 분리: 동일 성장 스냅샷/동일 입력 비교는 배치 효과를 분리한다. 자연 경로는 수입 차이로 구매 라운드가 달라질 수 있으므로 동일 구매 시점으로 강제하거나 돈을 채우지 않는다. 같은 구매 우선순위 정책을 유지하고 도달 전투수·실전초·부족 잔액을 비교한다.
4. 원시 기록: 라운드 종료이유/틱, 누적잔액·구매원장, 처치수/G, 공격 없는 틱, 파쇄/잔불/연쇄 발동, S01/S02 도달시점. G/활동전투초와 구매·상점 시간을 포함한 세션 효율을 구분한다. 활동시간0일 때 비율을 산출하지 않는다. 라운드G만 같아도 조기종료 시간은 달라질 수 있다.
5. 중단/판정: 결정성 실패, 지급/효과 회귀, 기본 화염 반복 무수입은 즉시 중단. 종료/구매 로그까지 보존해 원인 분리한다. F03의 '3시드 중 2시드 이상 G/활동전투초 차이20% 초과'는 조기 경고용 조건부 수용이며 승인 밸런스 합격선이 아니다. 대조군 수입0이면 상대비율을 억지 계산하지 말고 무수입 여부부터 보고한다. 장기 도달 실험은 전투수/시간 한도를 사전 정하고 초과 시 '그 한도 내 미도달'로 기록한다. 미도달을 영구 불가능으로 단정하지 않는다.

## 6. 대표 판단점 — Q1/Q2 구체 대안

### Q1: 조건부 수용 — 커서 보존 + 가장자리 예외를 권고
추천: C와 지휘원은 커서를 따르고, 중앙만 정확 고정각 원주. 경계에서는 종류 순서 유지 유효 원호, 부족하면 안쪽 압축을 허용하되 공격과 그림은 같은 실제 위치를 쓴다. 추가 조작 없음. 최소 패널 크기까지 지원하고 실패는 명시한다.
대안: C를 안쪽으로 밀어 원주 전체를 유지하면 수학은 단순해지지만 커서와 지휘가 달라진다. 커서 보존 요구를 버려야 하므로 비권고. 정확 원주를 절대 우선하면 경계 커서 사용 제한/클리핑 중 무엇을 감수할지도 결정해야 한다.
대표 질문: '가장자리에서 커서를 옮기지 않고 원호 재배치·안쪽 압축으로 최대거리/고정각 예외를 허용할까요? 지원 불가한 좁은 패널은 제한해도 될까요?'
최소 검증/중단: 3절 기하/실제 패널 검사. 예외 미허용인데 모든 표시 온전함까지 요구되면 동시 충족 불가를 보고하고 구현 확장 중단.

### Q2: 조건부 수용 — U05 연동 시험 권고, 조용한 공격거리 변경에는 반대
추천: 배치 목표 반경도 CommandRadius를 사용해 R 전후를 비교하되 공격거리3·피해·주기·효과·보상은 고정한다. 원주 제안과 일관되지만 U05의 체감/경제 의미가 달라진다. 경계에서는 압축으로 실제 배치거리가 R보다 작을 수 있음을 설명해야 한다.
최소 대안: 배치 반경을 기본값에 고정하고 U05는 기존 지휘원 내부 후보 우선 범위만 확대한다. 변수를 줄이지만 강화 뒤에는 '지휘원 최대 경계 배치'가 아니다. F01은 U05의 배치 연동을 약속하지 않았으므로 이 차이를 트리 설명에도 반영해야 한다.
대표 질문: 'U05가 지휘범위와 배치거리를 함께 늘리는 해석을 시험할까요, 아니면 배치거리 고정으로 공격 중심 변화는 제한할까요? 전자는 경제 변화도 감수하고 별도 비교해야 합니다.'
최소 검증/중단: U05 유무 각 상태에서 같은 입력/시드/종료판 비교 및 자연 경로 재생. 반복 무수입·큰 편향·성장 도달 지연이 확인되면 원인과 두 대안을 재상신하고 자동 보정하지 않는다.

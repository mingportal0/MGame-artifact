# F01~F08 전체 실행 승인

대표 최신 정정: “아니다. F01~F08 모두 실행 승인.”

기존 부분 승인·전원 실행 대기 안내보다 이번 지시가 우선한다. 8개 카드 모두 실행 승인됐으며 선행조건을 충족하면 같은 실행 승인 재요청 없이 진행한다. 완료마다 Slack 보고하며 중요한 사양 미합의·범위/비용 변경은 별도 판단 사항이다.

## 실행 순서
- James: F01 해금·성장 최소 규칙 → F03 정령 분산안 비교·구체화.
- Mia: F01 결과 → F02 전체화면·중앙 시작 트리 UX.
- Sam: F04 전멸 즉시 상점 → F05 한국어·첫 언어 선택 → F06 전용 해금·트리 구현 → F07 정령 분산 구현.
- F06은 F01·F02 결과도 필요하다. F07은 F03 결과도 필요하다.
- Sophie F08은 F04~F07 결과와 기존 D02 잔여 인수를 확인해 통합 인수·대표 재플레이를 취합한다. 이번 승인은 D02 미해결 검증을 자동 통과시키지 않는다.

동일 프로젝트 동시 쓰기 방지를 위한 직렬 의존을 추가했다. 원본 Unity/Editor 보호·기존 승인 격리 경로만 사용한다. 소스·빌드 외부공개나 새 비용 승인은 아니다.

## 정령 배치
정령이 커서 범위 최대 사거리 쪽에 있어 커서와 떨어지게 하자는 대표 제안을 F03의 우선 구체화 기준으로 삼는다. 커서 중심 지휘원 경계라는 해석과 정령 자체 공격 사거리는 구분한다. 각도·간격·화면 가장자리·이동·강화/경제 영향은 실제 검토 후 기록하고 중요한 상충 선택은 대표에게 확인한다. 세 안을 모두 구현하는 지시가 아니다.

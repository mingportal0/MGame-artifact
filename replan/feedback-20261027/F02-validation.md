# F02 v01 검증 기록
Mia / 2026-10-27 / 상태: 문서·정적 렌더링 검증 완료, 전문 검토 대기

## 실제 실행
브라우저로 F02-wide.svg와 F02-compact.svg 로컬 파일을 열고 CDP viewport를 각각1440×900,960×540으로 설정하여 스크린샷을 촬영했다. F02-wide.png/F02-compact.png가 그 결과다. SVG는 정적 와이어프레임이지 클릭·거래·스크롤이 구현된 게임 UI가 아니다.

브라우저 첫 렌더에서는 한국어 폰트 부재로 네모 글리프가 보였다. Google Fonts의 Noto Sans KR을 명시한 뒤 실제 재렌더링하여 한국어 표시를 육안 확인했다. 두 SVG 모두 document.fonts.check가 true, parsererror0, 모든 text getBBox의 캔버스 밖 넘침 목록은 빈 배열이었다. 넓은 지도는 각 g 안의 rect.node 대비 text 경계도 검사하여 넘침 목록이 빈 배열이었다. 모든 의미가 글자/체크/플러스/느낌표/테두리로 읽히고 색만으로 구분하지 않는 것을 정적 이미지에서 확인했다. 색각 사용자 관찰/스크린리더 테스트는 하지 않았다.

노드명 앞 ID를 DOM에서 추출·중복제거·정렬한 실제 결과:
ROOT, S01, S02, U01, U02, U03, U04, U05, U06, U07, U08, U09, U10, U11, U12.
필수선행 g.edge path 수14. 이는 ROOT 포함15개 표시/구매대상14개의 문서·지도 정합성 확인이며 도달성/구매 구현 실행 결과가 아니다.

긴 한국어 실험: 386px 폭,18px NotoKR, 줄높이27px,높이76px,overflow-y:auto/overflow-wrap:anywhere의 임시 브라우저 div를 SVG foreignObject 안에 넣었다. F02 본문의 긴 효과 문장을 입력한 실측은 clientWidth371/scrollWidth371/clientHeight76/scrollHeight81. 가로넘침 false, 세로스크롤 true. 임시 div는 실험 직후 제거했다. 이는 본문 줄바꿈/스크롤 방식의 제한된 렌더링 실험이며 실제 Unity UI나960×540 전체 인터랙션 검증이 아니다.

## 문서 기반 경계 사례 대조 — 실행 게임 시험 아님
- ROOT만/0G: 기본보유·구매불가와 무료 시작, 다음 목표 부족액 안내 계약 존재.
- ROOT만/충분한 잔액: S02/U06/U07 잠금과 명시 선행 이유 존재. S01 전투 경유 조건 없음.
- S01 소유: U07은 U06 없이, S02 소유: U08은 U09 없이 구매 가능한 형제 가지. 실제 SVG 실선은 해당 소환 노드에서 분기한다.
- 강화 순서: 화염3종은 ROOT에서 각각 직접 연결, 추천 텍스트가 구매 제한이 아니라고 명시.
- 적투자: 구매 보유와 무료토글 구분, OFF 재구매/환불 없음, 효과활성 집계와 소유 취득 건수 구분 계약 및 compact 예시 존재.
- 모든14개 획득: 배타·포기·구매수 문턱 없음. 실제 거래·도달성 검증은 F01 참조모델/향후 F06과 구분.
- 작은 화면: 960×540 정적 카드/상세/무료시작 캡처, 긴 문구 본문 대안 명시. 1280×720·640×480 Unity 적응형/Tab/입력관통은 미실행.

## 출처·재사용·남은 위험
Noto Sans KR CSS: https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap
원본 프로젝트의 라이선스 확인: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE (SIL OFL1.1,2026-10-27 실제 조회). 폰트 바이너리를 배포하지 않고 SVG에서 Google Fonts의 공개 ttf URL을 참조한다. 문서 렌더링 용도이며 게임 에셋 채택이 아니다. 오프라인/이미지 임베드 환경은 외부 폰트 로드가 차단될 수 있으므로 한국어가 확정 렌더된 PNG도 함께 제공한다. 도형·레이아웃은 이번 직접 작성, 타 게임 에셋 없음.
실제 Unity 거래·입력·포커스·한국어 폴백·게임 성능·사람 이해도/재미·가격 적정성 미검증.20/40G는 제안, 추가60G 지연 위험 유지. F04의 실행환경 차단과 D02 잔여 인수도 이번 문서 검증으로 해소되지 않는다.
무인 terminal의 python -c 가 single-query 정책으로 거절된 사실이 있다. 그 경로는 재시도/설정변경/다른 인터프리터 우회를 하지 않았고, 정적 파일 작성과 허용된 브라우저/CDP로 렌더링 확인만 수행했다. Unity·게임소스·빌드·공유 README 변경 없음.

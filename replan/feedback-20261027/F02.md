## 1. 플레이어가 보는 장면과 다음 행동
전투 종료 후 전투 화면을 덮는 전체화면 상점. 화면 중앙의 `시작 · 화염 기본 보유`를 기준으로 화염/얼음/번개/공통/적 투자 다섯 영역을 동시에 본다. 트리는 탐색 지도이지 강화 구매 순서를 강제하는 계단이 아니다. 먼저 노드를 선택하고 우측 상세에서 명시적 구매 버튼을 누른다. 노드 클릭만으로 결제하지 않는다.
상단: `상점 / 보유 {gold}G / 다음 전투 정령: 화염·{해금 종}`. 하단 고정: `다음 전투에 적용 {pending}건 / 적 설정 요약 / 다음 전투 시작(무료)` 및 `앱 종료 시 진행 초기화`. 정령 해금과 강화의 pending은 신규 구매 건수, 투자 설정은 별도 ON/OFF 요약으로 표시한다. 전체화면은 게임 내 패널이며 OS 전체화면 변경이 아니다.
첫 진입은 ROOT 선택, 키보드 포커스는 중앙 ROOT. 강제 튜토리얼/자동 구매/자동 전투 시작 없음. 0G에서도 `10G 더 모으면 화염 집중 구매 가능`과 무료 전투 시작을 함께 보여 막힘으로 오해하지 않게 한다. 문구는 목표 제안이며 가격/잔액을 런타임 데이터에서 읽는다.

## 2. 실제 와이어프레임 파일과 레이아웃
- [1440×900 전체 지도](F02-wide.svg): 시작 ROOT를 트리 가용 영역 중앙에 둔 정적 와이어프레임. 잔액15G·ROOT만 보유·U01 선택의 예시이며 실행 가능한 상점이 아니다.
- [960×540 축약 레이아웃](F02-compact.svg): 한 화면에 전체 지도와 긴 상세를 축소 압축하지 않고, 중앙 시작 요약+5개 가지 필터+선택 가지 목록+상세 패널을 보여 준다. 필터는 표시만 바꾸고 구매/잠금을 바꾸지 않는다.
넓은 모드(가로1280 이상·세로720 이상): 상단76/하단92, 우측 상세320, 나머지 트리. 노드 최소148×64, 노드 간16 이상, 클릭 영역44 이상, 본문18px·상태16px·제목22px을 기준으로 한다. 좌표는 와이어프레임 가이드이며 Unity Canvas 실측으로 최종 보정한다.
작은 모드: 지도 좌표 전체 축소 금지. 상단72/하단64를 고정하고 남은 영역을 목록55%/상세45%로 분리, 각각 독립 세로 스크롤. ROOT와 가지 필터를 위에 고정한다. 가로800 미만 또는 세로500 미만이면 상세를 단일 열 화면으로 전환하고 `목록으로`로 복귀, 같은 선택/스크롤 위치 보존. 640×480까지 필수 조작 유지가 목표이며 그 이하에는 최소 창 크기 안내. 실제 지원 해상도/렌더링 수용은 F06 시험 대상.
이 범위의14개 구매 노드에는 이동/확대 기능을 도입하지 않는다. 휠은 넘치는 목록/상세 스크롤만 담당. 가지 이동/중앙으로 버튼과 화면 크기별 재배치가 드래그 팬/줌보다 비용이 작다는 Mia 권고이며 Sam 비용 검토 전 확정 견적이 아니다.

## 4. 상태·비색상 표식·행동
기본 상태 우선순위: ROOT 기본보유 → 소유 → 선행미충족 → 잔액부족 → 구매가능. `선택`, `포커스`, `다음 전투 적용`은 기본 상태 위에 겹치는 보조 표식이다. 비용0G인 ROOT를 구매가능으로 계산하지 않는다.

|상태|색 외 구별|선택 시 상세/CTA|문구 ID|
|---|---|---|---|
|잠금|사각 잠금 표식+`잠김`·점선 테두리|`얼음 정령 소환이 필요합니다` / 구매 비활성, 선행 보기 활성|shop.state.locked|

잠김이어도 포커스/선택은 가능하고 이유를 읽을 수 있다. 잠금과 잔액 부족이 동시에 발생하면 선행 이유를 우선하고 상세에서 가격·현재 잔액을 함께 보여 준다. 부족액은 선행을 충족한 뒤 CTA에 표시한다. 토글은 구매 버튼과 hitbox를 분리하며 잠긴 투자에 OFF 스위치를 노출하지 않는다.
툴팁: hover250ms/키보드 포커스에 이름·가격·상태·선행 한 줄 표시. 모든 정보는 클릭 고정 상세에도 있어 hover 필수 아님. 화면 가장자리에서 좌우 반전·가용폭 내 줄바꿈. 긴 효과는 툴팁에 모두 넣지 않는다.

## 5. 거래·다음 전투·입력 흐름
노드 선택 → 상세 확인 → 명시적 구매 클릭 → F01 검증 → 차감/소유 원자 확정 → 같은 노드에 포커스 유지 → 잔액/해금된 이웃/다음 전투 요약 즉시 갱신. 실패하면 상태를 다시 읽고 `구매 실패: {reason}`를 상세 안에 유지, 잔액/소유 변화 없음. 확인 모달·환불 기능 추가 없음.
S01 구매 직후 S02/U06/U07은 같은 상점에서 구매 가능(잔액 충족 시). 정령은 아직 전장에 생성하지 않는다. pending 배지는 전투 시작 스냅샷 확정 후 제거하고, 이미 보유한 효과는 재진입 시 `보유`로 남는다. 새 구매0건이어도 투자 토글의 변경 요약은 보여 준다. 적투자 OFF는 소유 취소가 아니며 다음 번 ON도 무료. 투자 노드는 일반적인 `다음 전투 적용` 대신 `보유 · 다음 설정 ON/OFF`를 사용한다. OFF면 효과 적용 예정으로 세지 않고, 신규 구매 건수는 소유 취득 기록일 뿐 활성 효과 수가 아님을 요약에 명시한다.
구매 피드백은 노드 체크 전환과 잔액 숫자 갱신, 상세 내 `구매 완료 · 다음 전투 적용`. 선택적으로 단발150ms 테두리/짧은1음만 사용. 연속 반짝임·화면 흔들림·색상만의 성공 신호 없음. 음소거에서도 동일 정보. 새 커스텀 에셋 없이 공통 카드/기본 도형/라인/텍스트 배지 재사용.
상점이 열린 동안 전장 지휘/공격/시간 진행을 차단. 진입 프레임의 pointer-up/held key는 구매/시작으로 넘기지 않음. 전투 시작도 새 press-edge 한 번만 처리하며 누르고 있던 클릭은 전장 명령으로 이어지지 않게 한다. 창 포커스 복귀 시 held 입력 초기화. 정확한 입력 차단 방식은 Sam 책임, 실제 검증 필요.
닫기/X로 전투 재개하는 경로 없음. Esc는 툴팁/상세 단일열을 먼저 닫고 상점 자체는 유지. `다음 전투 시작(무료)`만 명시적 이탈. 앱 종료/새 게임은 F01의0G/ROOT 초기화 계약을 따르며 저장됨/영구 성장이라는 문구 금지.

## 6. 포커스·탐색·긴 한국어
Tab 순서: ROOT → S01 → U06 → U07 → S02 → U08 → U09 → U01 → U02 → U03 → U04 → U05 → U10 → U11 → U12 → 선택 상세의 선행/구매/토글 → 무료 전투 시작 → 순환. Shift+Tab 역순. 기본 구매 불가 노드도 정보 접근 가능하며 상세의 비활성 구매버튼 자체는 Tab에서 제외. Enter/Space는 노드에서는 선택만, 구매 CTA에서만 결제. 화살표는 같은 가지 내 이전/다음, 가지 처음/끝에서는 그 가지 헤더로 이동. 모드 전환/필터 변경은 선택ID 유지, 숨겨진 선택이면 해당 가지 자동 노출, auto-scroll로 포커스 가림 방지. 컨트롤러 전용 조작은 이번 범위 밖.
긴 한국어 사례: `다음 전투부터 둔화된 적이 사망하면 주변의 다른 적에게 추가 피해를 줍니다. 얼음 둔화 강화는 먼저 구매하지 않아도 됩니다.` 상세 본문은 줄바꿈+세로스크롤, 가격/CTA는 고정 하단. 제목은2줄 이후 말줄임+상세 전체명, 상태는 최소2줄 확보, 숫자/단위를 함께 유지. 폰트 축소로 맞추지 않는다. 잠금 이유 예: `먼저 얼음 정령 소환을 구매해야 번개 정령 소환을 구매할 수 있습니다.`도 상세에서 잘리지 않아야 한다. 폰트 폴백/한국어 글리프는 F05/F06 실제 빌드에서 확인.

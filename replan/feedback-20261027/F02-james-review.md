## 1. 결론 — 지도를 수용하고 구매 순서를 새로 강제하지 않는다

중앙 ROOT에서 정령 소환과 독립 강화를 구별하는 구조는 F01을 훼손하지 않는다. 문서의 선행 규칙과 실제 SVG 경로를 대조했을 때, 강화를 차례로 사야 하는 새 조건이나 영구 배타 가지는 발견하지 못했다. 따라서 핵심 규칙 충돌로 F02를 중단할 사유는 없다.

재미 가설은 ‘강화 속도 증가’만이 아니라 다음 전투에서 얼음 둔화와 번개 연쇄 등 새 행동을 예측하고 선택하는 데 있다. 다만 지도에 목표가 보인다는 사실만으로 실제 소환까지의 기다림이 재미있다는 결론은 낼 수 없다. 20/40G는 시험 제안으로만 수용한다.

조건은 두 종류다. 아래 문구 보완은 Mia가 F02에서 처리·채택 여부를 기록할 사항이고, 실제 구매·토글·스냅샷 동작은 기존 F06에서 증빙할 사항이다. 이 리뷰 때문에 별도 기능이나 새 승인을 추가하지 않는다.

## 3. 구체 이견·조건부 수용 사항

### C1 — ‘다음 전투 적용 N건’과 ‘신규 구매 N건’은 같은 뜻이 아니다

근거: F02 §1은 ‘다음 전투에 적용 {pending}건’을 신규 구매 건수로 정의하고, §5는 OFF 투자에 효과 적용 배지를 쓰지 않도록 한다. wide 하단은 ‘다음 전투 적용: 신규 구매 0건’이다. 이 예시는 신규 구매가 없어 모순이 드러나지 않지만, 투자 구매 직후 OFF로 바꾸면 소유 취득은 있고 활성 효과는 없다.

요청: 거래 수를 표시한다면 ‘신규 구매 N건’으로 명명하고, ‘다음 전투 정령’ 및 ‘적 다음 설정 ON/OFF’를 별도 요약으로 유지한다. 효과 적용 수로 읽히는 제목 아래 취득 건수를 넣지 않는다. 기존 §5 규칙을 더 명확히 표현하는 보완이며 새 카운터 기능을 요구하지 않는다. OFF를 활성 효과로 집계하는 구현은 불수용이다.

### C2 — compact는 세 상태의 분리를 설명하지만 적용 중 값은 보여 주지 않는다

근거: compact 상세는 ‘적용 중 설정과 다음 설정은 별개입니다’라고 쓰지만 실제 적용 중 값은 제시하지 않는다. 보유/다음 OFF의 구분은 충분히 명시되어 있다. 그러나 직전 전투가 ON이고 다음 전투만 OFF인 경우를 현재 그림만으로 입증할 수 없다.

요청: 기존 F02 §4의 ‘적용 중 요약’을 구현에 인계할 때, 상점에서는 ‘직전 전투 적용: ON / 다음 전투: OFF’처럼 시점이 드러나게 하거나 전투 중에만 ‘적용 중’으로 표시한다는 표시 위치를 명시한다. 상점에는 진행 중 전투가 없으므로 과거 스냅샷을 현재 활성 효과로 오인시키지 말 것. 표시 방법의 최종 UX 선택은 Mia 책임이며, 저장 구조나 토글 규칙 변경은 필요 없다.

### C3 — 행동 변화는 일부 선택 상세에만 있으므로 사람 이해도 확인이 남는다

wide는 U01의 피해 변화, compact는 U10의 공급 변화 예시다. S01/S02를 선택했을 때 새 정령과 적용 시점이 실제로 읽히는지는 이 두 정적 장면만으로 확인하지 못했다. F02 표의 얼음/번개 효과 문구는 수용한다. 신규 아이콘이나 튜토리얼을 추가하기보다, 기존 상세에 ‘다음 전투부터 정령 1개’와 효과를 유지한 채 설명 없이 목표를 찾을 수 있는지 확인하는 것이 우선이다.

## 4. 가장 싼 검증과 불수용 반례 — 기존 F06 범위에 인계

아래는 실행 결과가 아니라 요구·제안이다. 새 개발 카드 생성이나 구현 착수를 지시하지 않는다.

- 선행 반례: 충분한 G와 S01만 보유한 상점에서 U06 없이 U07을 구매한다. S02 보유 뒤 U09 없이 U08을 구매한다. 어느 쪽이든 강화 미보유로 거절되면 F01 위반이다.
- 같은 상점 연속 거래: S01 구매 직후 S02/전용 강화 CTA와 잔액이 갱신되되 전장 정령은 생성되지 않아야 한다. 다음 전투에서만 보유 종별 최대 1개를 생성한다. 재도전 시에도 누적 생성하지 않는다.
- 토글 반례: U10 구매 → 기본 ON → 즉시 OFF → 무료 ON으로 전환한다. 구매 차감은 최초 한 번뿐, 보유 체크 유지, 다음 설정만 변경, 기존 적용 스냅샷 불변이어야 한다. OFF 구간을 활성 효과로 보고하면 실패다.
- 전체 획득: 모든 구매 노드 보유 후 ROOT 및 보유 노드 재구매 불가, 다른 가지 영구 차단 없음, 무료 다음 전투 가능을 확인한다. 2/5개 구매 자동 지급을 별도로 부정 시험한다.
- 자연경제: 적 투자 OFF·초기금/Hit 주입 없이 화염 시작에서 실제 수입으로 S01→S02까지의 전투 수·시간·강화 보류를 기록한다. 무수입 반복 또는 과도한 대기라면 먼저 시험 가격을 재검토한다. 현재 성공·적정시간으로 판정하지 않는다.
- 사람 이해도 최소 관찰: 기존 정적 그림/선택 상세를 이용해 처음 보는 사람에게 ‘얼음 파쇄에 둔화 구매가 필요한가’, ‘추천 밖 화염 확산을 지금 살 수 있는가’, ‘보유 OFF 투자를 다시 켜면 돈을 내는가’, ‘소환은 언제 나타나는가’를 묻는다. 정답 설명 전에 오답·설명 요청을 기록한다. 이는 제안이며 이번 검토에 참가자 관찰은 없다.

## 5. 실제 수행·미수행과 인계

실제 수행: 공통 AGENTS/README, 최신 실행 승인 원문, F01/F02 전체 문서와 두 실제 SVG의 XML·텍스트·좌표 경로를 읽고 규칙 대조했다. wide 파일은 브라우저로 열어 해당 파일 URL/페이지 크기 반환까지 확인했다. 렌더링 스크린샷 획득은 도구 타임아웃으로 실패했으므로 시각 렌더링 합격이나 글리프/잘림 확인을 주장하지 않는다. 별도 Python 자동 검사는 무인 실행 승인 정책으로 실행되지 않았으며 자동 통과 수치를 보고하지 않는다. 최초 셸 기본 작업 경로 오류는 명시적 작업 workspace 지정으로 해소했다.

미수행: Unity/게임 코드 변경·실행, 실제 거래·키보드·포커스·해상도·성능 시험, 사용자/재미 실험, 새 자연수입 경로 실측, 외부 저장소 게시·Slack 발송. 문서와 SVG 소스 검토는 이러한 실검증을 대체하지 않는다.

변경 파일은 이 응답 문서뿐이다. F01/F02 원문, SVG 및 공유 README는 수정하지 않았다. C1/C2의 채택·표현 보완 및 공개본 정리/완료 보고는 Mia F02에 인계한다. Sam 비용 검토는 별도 실제 응답으로 받아야 하며 이 검토가 대신 동의하지 않는다. 본 카드 완료는 James 응답 제출 완료만 뜻하며 F02/F06 또는 D02 잔여 인수를 완료 처리하지 않는다.

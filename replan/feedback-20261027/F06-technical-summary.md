# F06 전용 해금·전체화면 트리 — 기술 결과
문서ID P1-F06-TECH-v02 / 담당 Sam / 2026-10-29
상태: 승인 범위 구현·격리 기능검증 완료. 대표 최종 인수와 별개.

## 구현
화염 기본 보유와 전용 얼음 S01·번개 S02를 분리했다. 기존 구매수2/5 자동해금은 제거했다. 해금 시험가격20/40G는 개별 밸런스 최종채택이 아니다. 기존12개 효과/가격과 강화 독립성, 적투자3축 무료토글을 유지한다. 해금은 동기 거래로 차감·소유 확정되며 중복결제/잠금우회를 거부한다. 상점에서 필드 개체를 추가하지 않고 다음 전투에 종별1개를 재생성한다.

ROOT는 구매불가이며 총14개 구매항목을 모두 얻을 수 있다. 중앙 ROOT 전체지도와 좁은 화면 목록/상세를 구현했다. 명시 구매CTA, 선행보기, 선택필수경로 강조, 모드별 Tab/역Tab 및 고정가격/무료시작을 제공한다. 앱 종료 시 진행 초기화, 언어만 저장한다. U05 설명은 지휘범위와 배치 목표 연동·공격거리 불변을 구별하며 실제 배치 변경은 F07 후속이다.

## 실제 실행 결과
Unity 6000.6.7f1 Windows64 승인 격리본만 사용했다. 최종 EditMode NUnit12/12, 전체 PlayMode NUnit3/3. Play 내부 F06검사121/121·언어회귀24/24는 NUnit 수와 별개다. 최종 빌드출력/독립전달폴더/ZIP재추출 각각125/125·실패0·프로세스exit0. 반복실행을 고유시험 수로 합산하지 않는다.

1920×1080·1440×900·1280×720 지도,960×540 분할목록,640×480 단일열 × 한국어/영어의 실제 Screen/root/모드 일치 및 카드/글자경계·무관카드 선교차·필터·고지·CTA·Tab/역Tab을 검사했다. UI Toolkit 합성 이벤트와 콜백이며 물리 OS입력은 아니다.

0G 자연수입 UI경로는 투자OFF 3라운드80G 수입, U01/S01/S02 70G지출,10G잔액 및 다음전투3종을 확인했다. 전체14개/390G 도달은 별도 모델 자연경로로 확인했고 자금주입 UI14개 거래와 구분한다. 장기경제·모든전략·사람재미 증명이 아니다.

원본 보호75파일 불변. MGAME 소스59파일의 내부/격리/보존snapshot 일치, 빌드/전달/내부보관/ZIP추출201파일 일치, ZIP CRC 및 재추출실행 확인. 전투 계산 구간과 폰트는 이전 단계와 동일하다. 소스·빌드·폰트는 외부 게시하지 않았다.

## 실행과 남은 범위
내부 전달폴더 전체를 유지하여 실행 → 언어선택 → 마우스로 전장지휘 → 상점 노드선택 → 상세 구매 → 무료 다음전투. 상세 구매버튼에 포커스 후 명시 제출은 구매지만 노드선택은 구매가 아니다.

# F07 가독성·지원제한 전문 검토 요약

문서ID: P1-F07-UX-SUMMARY-v01 / 작성: Sam
근거: Mia가 실제 작성한 F07 구현 검토 v01/v02/v03. 본 요약은 새로운 Mia 승인이나 대표 최종 비주얼 승인본이 아니다.

## 실제 수용한 범위
1. 지정 1280×720 한국어/영어 중앙·네 모서리에서 F/I/L 정령, 종류명, 단일 적 A/HP의 안정 분리를 실제 화면으로 확인했다. 1440×900·1920×1080은 지정 중앙 화면을 확인했다.
2. 작은 화면의 상점을 유지하면서 전투 시작을 막고, 전투 중 축소 시 일시정지·재개 비활성, 확대 후 명시적 재개를 요구하는 수정판을 지정 한/영 화면에서 수용했다. 안내는 시작 버튼 옆과 Pause 덮개 안에 고정 표시한다. 언어설정은 기존 흐름을 보존한다.
3. 지정 단일 적 fixture에서 실제 3종 주공격 발사선의 출발과 적 도착, 종류/체력 표시를 확인했다. 기록의 Trace.Tick600과 Step후601시점을 구별했다.
4. 최종 추가 검토는 한국어/영어 외부 사격→내부 사격 원본4프레임과 실제 틱을 대조했다. Tick0 외부 사격 중 내부 접근 기억이 유지되고, Tick20 내부 사거리 진입 후에는 쿨다운을 기다리며, Tick45 내부 사격으로 바뀌는 지정 증빙을 수용했다. 해당 범위의 추가 필수 코드 수정은 요구하지 않았다.

## 지원제한
지원 사전조건은 실제 전장 width>=184px, height>=154px 및 커서 모서리에서 토큰 전체를 수용하는 조건이다. 이는 모든 적 밀도에서 배치 가능한 수학적 보장이 아니다. 현재 측정한 960×540/640×480 화면은 전투 공간 미지원이다. 이 크기에서도 상점·구매·설정을 사용할 수 있지만 전투 시작/재개는 막는다. 권장1280×720에서도 DPI나 추가 안내로 공간이 부족하면 경고를 유지한다.

## 미수용·미검증
- 급이동 t15/t300 두 화면은 안정 복귀 증빙일 뿐 전 구간의 사람 추적 능력이나 무겹침을 증명하지 않는다. overlapAtTicks는 초기 이동의 전수 기록이며 급이동 전수 기록으로 바꾸어 해석하지 않는다.
- 그림을 고정해 비교한 검토는 실제 사람의 동적 지휘 이해, 고밀도 전장, 모든 DPI, 물리 입력/접근성, 최종 비주얼 승인과 다르다.
- Mia는 최종 전달물 전체의 모든 PNG·DLL·ZIP을 검증하지 않았다. 소스/실행물 일치와 실제 전달폴더/ZIP 재추출 실행은 Sam의 별도 기능 검증이다.
- 최초 좁은 화면의 겹침/제한 UX 누락 및 후속 발사선 fixture의 검증 공백은 실패 이력으로 보존한다. 최종335검사 성공을 이전 검토 시점의 성공으로 소급하지 않는다.

결론: 지정 안정 배치·시작/재개 제한·실제 발사선과 접근 전환 증빙의 전문 제한 수용이다. 사람 UX·재미·최종 비주얼·D02/F08 전체 인수 완료는 아니다. 소스·빌드·원시 화면 및 내부 계정 경로는 공개하지 않는다.

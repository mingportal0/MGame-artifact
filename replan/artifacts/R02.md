## 실제 응답과 반영
- 전체 목표: 빠른 플레이 가능 데모 중심으로 수정. 긴 기획 완성을 데모의 선행조건으로 쌓지 않는다.
- Q1 실제 응답: ‘독립 업그레이드로 진행. 권고안은 긍정적으로 봄.’ 독립 업그레이드 방식 확정. 단순 복제·반복레벨로 수량 채우지 않는다. 배분16/12/12/20/20/20 및 행동변화56/수치44는 긍정 평가된 참고 예산이며 고정 확정값으로 취급하지 않는다. 기존 최소100개 정도 전체 목표는 명시 폐기되지 않았고 첫 데모 수량 축소는 별도 범위 승인 대상이다.
- Q2 실제 응답: ‘권고안 채택’. 화염 기본1개→얼음→번개 순서, 각각 해금 시 기본1개를 별도 구매 없이 자동 지급. 문턱은 잠긴 원소 제외 가용 재고·화염 단독 수입 검토 후 재제안. 기존12/35/65는 미확정.
- Q3 실제 응답: ‘A안 승인’. 전부 구매는 선택, 전부 구매 시 완성 표시·자동 종료 없음. 이후 새 성장/환생 없음. B 전체 구매 강제 완주/C 별도 과제는 미채택.

## 후속 경로와 유보
[데모 우선 전환안](../demo-first-plan.md): 작은 독립 업그레이드 표본→실행 가능한 데모→짧은 실플레이 검토를 권고.12개 내외·브라우저·임시 도형은 제안이며 승인 사양이 아니다.
R03~R15는 기존 장기 기획 경로로 자동 실행하지 않고 blocked 유지. 이번 기준을 계약·보드에 전파한 뒤 차기 단일 범위 확정 단계 승인을 요청한다. G3 개발·기술 확정·초기화·지출·신규 공개는 미승인.
미결정은 가격/해금 문턱/데모 포함 수량·최소 적/저장/환경/일정이다. R02 답변 부재로 다시 막지 않고 후속 범위 확인 대상으로 명시한다.

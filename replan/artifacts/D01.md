## 2. 독립12개 표본 — James 제안, 수치·가격·문턱 미확정

모두 독립 효과·1회 구매이며 반복 레벨로 개수를 채우지 않는다. 다른 구매를 선행 강제하지 않되 원소 항목은 해당 원소 해금 필요. 해금 자동 지급 자체는 구매 수에 포함하지 않는다.

해금 문턱 제안은 서로 다른 항목2개→얼음, 5개→번개. 잠긴 원소를 제외해도 첫2개·첫5개를 살 수 있다. U03 지속시간·피해량, U07 피해량·범위, 기본 공격 주기·이동·배치 등은 Sam/James의 구현 전 세부 협의 대상이다. 세부값을 확정 사양이나 시험 통과로 취급하지 않는다.

## 3. 적 투자 전후 — 공급·실제 처치·금화 구분

James 제안 적 A 잿빛 슬라임/B 먼지 벌레는 각 HP10·1G, C 돌껍질 슬라임/D 철갑 벌레는 각 HP20·3G. 이름은 가칭이며 같은 수치 두 종에 전술 차별화를 주장하지 않는다. A/B/C/D 슬롯은 기본15/15/0/0, U11만10/10/5/5, U10만23/22/0/0, U10+U11은15/15/8/7. 시작에 전부 공급·종별 몰림 없이 섞음·자동 보충 없음.

U12는 종류 확정 후 슬롯마다 독립20%로 대체하며 추가 생성·확정 개수·재추첨 없음. 원래 HP×3·처치G×5를 각1회 적용: 기본 엘리트 HP30·5G, 새 적 엘리트 HP60·15G. 아래는 단독 구매 비교이며 복합 구매로 일반화하지 않는다.

| 같은 30초 유효 피해 예산900·모든 적 공격 가능 가정 | 공급 | 실제 처치 조건 | 금화(구매비 제외) |
| --- | --- | --- | --- |
| 구매 전 | 30 | HP합300 전부 처치 | 30G |
| U10만 | 45 | HP합450 전부 처치 | 45G |
| U11만 | 30(기본20+새10) | HP합400 전부 처치 | 50G |
| U12만 | 30 | 최대HP900까지 전부 처치 가능 가정 | 실제30+4E G, E=실제 엘리트 처치 수. 기대54G·매회 보장 아님 |

U12의 기대 출현6체·기대HP420은 실측이 아니다. 같은 처리량300이면 U10 구매 전후 최대30처치·30G로 수입 증가가 없을 수 있다. U11에서 기본20+새5만 처치하면25처치·35G이지 공급 보상50G가 아니다. 구매비20/25/30G를 뺀 첫 전투 순금화는 위 이상조건에서25/25/기대24G로 구매 전30G보다 낮다. 회수 기간·실제 플레이 수입은 미검증이다. 적 투자3종 결합은 기대 보상과 최대HP가 달라 별도 시험한다.

## 4. 표시·실행·시험·중단 기준

- Mia 최소 표시: 전투 남은시간/금화/지휘범위/정령, 처치 자동 지급; 상점 가격·효과·부족·미구매·구매완료·잠금 사유; 구매 전 ‘공급/구성 변화 → 더 처치하면 보상 증가 기대 → 처리량 초과·미처치 위험’. 잠긴 얼음·번개 조건/진척·해금시 자동1회/별도 구매 불필요를 표시한다.
- U12는 슬롯별 독립20%·미등장 가능·고정금화 보장 아님을 표시. 독립 구매와 확률 독립을 구별한다. 토글은 구매 버튼과 분리하여 ‘무료 설정·보유 유지·환불 없음·다음 라운드 적용’을 표시. 엘리트는 색 외 표식도 병용한다. 종료 획득 내역은 추가 지급이 아니다.
- 거래/지급: 상점에서 상태·잠금·잔액 재검사 후 비용 차감/소유/효과/해금 판정/원소별 지급기록을 함께 확정하거나 모두 취소. 처치ID·원소별 지급기록으로 중복 금지. 재도전 무료·금화/구매/해금 유지, 적/시계/공격잔여 초기화·엘리트 새 추첨. 종료 잔존 적은 무보상 제거·기지급 유지.
- 실행 제안: 대표의 범위·기술·G3·D02 명시 승인 후 Sam 구현. 브라우저 후보 채택 시 `npm ci`, `npm run dev -- --host 127.0.0.1`은 향후 명령 후보일 뿐 현재 프로젝트/지원/성공 확인 아님. 산출물 위치는 승인 시 지정. 설치·초기화·실행은 이번에 하지 않음.
- D02 인수시험 제안: 기본 화염 양의 반복수입/최초 구매/2개·5개 해금/잠긴 항목 거절/지급1회; 잔액 부족·연속 클릭·재진입·토글 무차감; 30초 직전/정각/직후·경계 넘는 프레임·종료 후 공격/생성 차단·중복 처치/정산 금지; UI 관통·포커스 복귀; 적3축 단독 및8조합의 공급/처치/실제G/구매비 별도 로그, 고정시드 재현 및 복수시드 빈도 검사. 시드·표본 수·오차는 Sam 제안 후 사전 합의, 수익은 기대값과 개별 결과 분리.
- 성능 제안(Sam): 합의 기기에서45적·합의 최대 정령/효과로 활성 전투 프레임시간 p95≤33.3ms. 기기/OS/브라우저 버전/해상도·효과상한·반복라운드 수·메모리 허용증가는 아직 합의 필요. 45적은 공급 제안이지 실측 성능 한계 아님.
- 중단/재승인: 승인 부재, 기본 화염 반복진행 불가, 중복 차감/지급·종료 후 보상, 비활성 미적용, 확률 재현 불가, 합의 성능 미달이면 구현 진행 또는 인수 중단·수정/재시험. 범위삭제·공급축소·비용증가가 필요하면 대표 재승인. 기능 통과는 재미·UX 통과 아님.
- D03는 별도 승인 후 James 게임성/Mia 사용성/Sam 결함 검토. 실제 참여자가 효과·기대·위험과 ‘엘리트 미등장 가능’을 설명하는지 관찰. 현재 실제 플레이어·런타임·성능·자연경제·재미 검증은 전부 미수행이다.

## 5. 대표에게 필요한 결정 — 다음 실행은 자동 허가 아님

1. 위12개 표본·일반4종·3정령·세션저장없음·임시표현을 첫 데모 범위로 채택할지(전체100개 목표 유지).
2. 가격·효과·2/5문턱·적구성/20%·토글/종료/포커스 규칙을 잠정 시험값으로 채택할지. 불완전한 세부 전투값은 James/Sam이 제안하고 범위영향 시 다시 확인.
3. Sam의 브라우저 후보 또는 대안·목표 기기·성능/확률 시험조건·산출물 경로/작업량 확인 방식 선택.
4. 범위·기술·예산/일정 제약·중단조건을 확인한 뒤 G3와 D02를 별도로 명시 승인할지. 현재 개발/프로젝트 초기화 미착수. D03와 기존 R03~R15는 계속 별도 승인 대기다.

D01 완료는 ‘승인 가능한 자료 취합’의 완료일 뿐 위 선택의 대표 승인이나 다음 카드 실행 허가가 아니다.

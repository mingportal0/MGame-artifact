# MGAME — Phase1 검토 산출물

휴대폰에서는 아래 문서 링크를 눌러 검토해 주세요. `artifacts/`는 회사 공유 폴더의 원본을 그대로 복사한 검토용 스냅샷입니다.

## 권장 검토 순서

1. **[대표 최종 확인 요청 — Q1~Q3](artifacts/23.md)**: 지금 필요한 결정과 승인 경계
2. **[최종 제출 안내](artifacts/22-submit.md)**: 제출 자료 및 잔여 위험
3. **[GDD Part1~10 본문](artifacts/22.md)**
4. **[정정 부록 E01~E04](artifacts/22-addendum.md)**: 본문과 반드시 함께 검토
5. **[검토 지적 대응 원장](artifacts/22-resolutions.md)**
6. [전체 산출물 폴더](artifacts/)

## 현재 상태

- P1-22 산출물 작성 완료와 최종 GDD 승인은 별개입니다. 제출 문서는 검토 중이며 대표의 최종 응답을 기다립니다.
- P1-23은 Q1~Q3 응답 대기입니다. 이번 업로드는 문서 승인, Phase1 종결 또는 개발 착수 승인이 아닙니다.
- 핵심 잔여: 개화 단독 OR 경로에서 지연 2초·타격손실 0의 조건부 계산으로도 피해 299 < 보스 HP 300입니다. 실제 플레이·자연경제·재미·성능 검증 결과는 없습니다.
- 대표 검토 후에도 후속 카드는 각각 별도 실행 승인을 받아야 합니다.

## 원본과 링크에 관한 안내

- 업로드 범위는 `game-planning-phase1/artifacts/` 전체입니다. 회사의 다른 폴더와 승인 기록은 포함하지 않았습니다.
- 산출물 간 상대 링크는 이 폴더 안에서 확인할 수 있습니다. 원본의 회사 로컬 절대경로나 `../../../decisions/` 등 Artifact 폴더 밖을 향하는 링크는 이 저장소에서 열리지 않을 수 있습니다.
- 산출물 안의 과거 상태는 당시 기록입니다. 최신 결정 요청은 위 `23.md`, 제출 기준은 `22.md`와 `22-addendum.md`를 함께 확인해 주세요.
- 계산·검사 파일은 기존 증빙을 보존한 것이며 이번 업로드 과정에서 게임 검증을 새로 수행한 것은 아닙니다.
